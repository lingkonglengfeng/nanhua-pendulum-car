# 四驱倒立摆的接线与接口方案

> 此文为 V1 功能接线方案。工程内主控原理图和 IO 表核对后的实际引脚、CN8/CN10 针号与低压信号转接板建议，见 [DMG474 引脚与转接板方案 V2](DMG474引脚与转接板方案_V2.md)。以下关于“主控原理图尚未确认”和“暂不建议转接板”的判断已由 V2 更新。

## 是否需要另画转接 PCB

目前不必先设计新的驱动 PCB。使用图示主控、**四块单路 DRV8871 模块**、现成分电端子和可靠线束，就能实现图中的模块连接。电机电流应由分电端子直接送到驱动模块，再回到电池负端，不经主控排针供电。

自制小转接板的价值主要是整理电源、四组控制线、四组编码器线、AS5600/IMU 接口和固定插头。它不会自动增加 MCU 的 GPIO 或硬件编码器资源。在没有确认主控原理图之前，不宜把具体 MCU 引脚焊死到转接 PCB。

如果后续制作，可包含电池/保险/开关端子、四组驱动供电端子、四组控制接口、四组编码器接口和一个低压 I²C 接口。不需要在转接板上重复搭建已经由 DRV8871 模块完成的 H 桥。各连接器额定电流、铜箔与线径应按实际电流选型。

机械安装片是另一件事：官方页面给出的主板外形为 152×87.5 mm，之前整车主控是较小的占位外形。还需要其安装孔尺寸才能决定是否加机械固定转接片；这不等于必须画电路 PCB。

## 主控识别和资源限制

最新照片板上标注 ATK-DMG474。ST 页面说明该板使用 STM32G474VET6，列出两组专用编码器接口和两组有刷/无刷驱动器接口。[官方合作伙伴介绍](https://www.stmcu.com.cn/hardwaredevelopmenttools/2878)

图示的四轮独立方案需要 4 路 PWM、4 路方向 GPIO、8 路 A/B 输入和 SDA/SCL。不能把两组板载编码器插座当作四组，也不能仅凭“通用输出/隔离输入”字样当作原始 3.3V GPIO。额外两组编码器的引出、计数器/中断资源以及已有外设冲突，需要查看主板原理图和固件。

SVG 中 `FL_PWM`、`FR_DIR`、`ENC_RL_A` 等是本方案定义的逻辑网络名，不是厂家排针丝印。没有填写 PAx/PBx 或排针号，是因为当前没有可核实的主板原理图；不能据此直接按照片上的绿色端子位置接线。

## 电源连接

1. 3S 电池放电端正极经 F1 和总开关 S0，形成 `VBAT_SW`；负极接 `GND` 分电点。
2. 主控接其专用 DC6–24V 电源输入：正端接 `VBAT_SW`，负端接 `GND`。DC 插座极性仍以实物/主板说明为准，不按插头外观猜。
3. `VBAT_SW` 再经电机电源开关 S1，形成 `VM_MOTOR`，分别接四块 DRV8871 的 `POWER +`。
4. 四块模块 `POWER −` 分别回到公共负端。信号地与功率地电气上共地，但大电流回路使用独立可靠连接，避免借主控细信号线回流。
5. 图中 U6 是独立的 3S 转 3.3V 辅助稳压模块，供轮速编码器、AS5600 和预留 IMU。它不是另一个主控电源，不要把其输出与主控板的 3.3V 输出并联。

若主板原理图确认其 3.3V 输出引脚和电流余量足够，可以省去 U6，改用主板的这一输出；这是二选一的供电方式。当前图选择独立稳压，是为了不假定未知的板载低压供电能力。

F1、开关和导线应按线材载流与实际峰值选。现已改选 370、280 转、带编码器的整套轮组，额定电压和电流尚待确认。此前 520 的 2.4A 堵转数据不再用于当前电源选型；四台电机的峰值总电流应按新套件数据重新核算。C1 的 470µF/35V 仅是电机母线储能起点，放在驱动模块附近，模块本地去耦、母线尖峰和回生情况还要检查。

## DRV8871 模块连接

| 模块端 | 本方案连接 |
|---|---|
| POWER + | VM_MOTOR |
| POWER − | GND |
| IN1 | 对应轮子的 PWM 输出 |
| IN2 | 对应轮子的方向 GPIO |
| 排针 GND | 与信号参考地同网 |
| MOTOR 1、MOTOR 2 | 只接这台电机的两根绕组线 |
| 排针 VCC | 本方案留空 |

照片中的 VCC 很可能是电机电源的另一处引出，不能当作 3.3V 逻辑电源。具体模块未提供背面走线或原理图，因此在断电状态下测它与 POWER+ 的通断；本图只使用明确标注的 POWER 电源端，不依赖这一 VCC 排针。

DRV8871 的输入允许 3.3V 逻辑，芯片带输入下拉和电流调节，3.6A 是峰值能力。模块实装的限流电阻与散热仍需确认。[TI 数据手册](https://www.ti.com/lit/ds/symlink/drv8871.pdf)

本图的 PWM+GPIO 接法规定：正向 IN1=PWM(d)、IN2=0；反向 IN1=PWM(1−d)、IN2=1；零命令统一将两输入置 0。它的正反衰减模式不同，不能把 IN2 改成 1 后仍原样使用 d。第二张 SVG 列出了芯片真值表。实际左右轮机械方向可能相反，调试时分别标定方向与编码器符号。

## 电机编码器和 AS5600

每台六线电机的两根电机线接该台驱动器，另外四根是编码器 VCC、GND、A、B。编码器按此前卖家图允许的 3.3V 方式供电，A/B 返回对应轮子的输入。线色只作为辅助，应按实物线序和厂家说明核对。

SVG 采用四路独立反馈，不把两台编码器的 A/B 输出直接并在一起。若 MCU 资源最终不足，要重新选择反馈方案或增加接口器件；不能仅通过分线插头把两组输入变成四组独立计数。

AS5600 功能连接为 VCC、GND、SDA、SCL，地址 0x36。所选圆板此前只有机械尺寸图，未提供 GH 插座针序和供电电路。只有确认它支持 3.3V 供电后，才按本图接 `3V3_SENS`；若只能用 5V，需要另核对 I²C 电平处理。图中引脚顺序仅示意功能，不代表 GH 插头顺序。[AS5600 数据手册](https://files.seeedstudio.com/wiki/Grove-12-bit-Magnetic-Rotary-Position-Sensor-AS5600/res/Magnetic%20Rotary%20Position%20Sensor%20AS5600%20Datasheet.pdf)

SDA/SCL 上拉到 3.3V。4.7kΩ 是短线起点，模块若已有上拉，先核对现有阻值和上拉电压，避免重复。可选 IMU 可共用总线，但需核对地址与电平。上杆的线束固定在支架外侧，避免拖动摆杆。

## 交付状态

两张 SVG 已解析并渲染检查；逻辑网络表检查了四路独立电机、电源域、公共地、未连接的驱动 VCC 排针，以及外部 3.3V 未与主板 3.3V 并联。`channel_assignment.csv` 对应轮子和网络名，`netlist.json` 记录连接关系。

尚未确认的是主控实际脚号、板上隔离/开漏接口的电气连接、另外两组编码器的资源、DRV8871 小板的实装限流值，以及 AS5600 插座针序。当前是信号级接线方案，不是可按端子位置直接插线的最终版本，也没有完成上电测试。
