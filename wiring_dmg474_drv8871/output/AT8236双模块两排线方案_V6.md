# 两块 AT8236 双路模块接四台 12V 电机（V6）

本版按所购小板的正面照片设计：**一块模块有 A/B 两路，两块模块驱动四台电机**。主板 DMG474 到转接板只接两根 24 芯 1:1 排线：`CN8 → J1`、`CN10 → J2`。IPS200、四路编码器和 AS5600 一起走这两根排线。绘图参考 [V6 SVG](08_AT8236双模块双牛角座_V6.svg)，逐网查 [主板接口 CSV](pin_assignment_v6_at8236.csv) 与 [AT8236 模块排针 CSV](AT8236_module_headers_v6.csv)。V5 TB6612 与 V4 DRV8871 已失效。

## 转接板接口和电源

| 转接板器件 | 连接 |
|---|---|
| J1，2×12 牛角座 | DMG474 CN8 / PM1，逐针 1:1；CN8-23 的 5V 留空 |
| J2，2×12 牛角座 | DMG474 CN10 / PM2，逐针 1:1；CN10-23 的 5V 只送 U_REG 输入 |
| U_REG，5V→3.3V | 输出 `3V3_LOCAL`，供两块 AT8236 的 VCC、四个编码器、AS5600、IPS200；容量、去耦和散热按实物负载核算 |
| AT_FRONT，两排各 7 针 | A 路接左前 FL，B 路接右前 FR |
| AT_REAR，两排各 7 针 | A 路接左后 RL，B 路接右后 RR |
| J_IPS，本板自定义 8 针 | 1 GND、2 3V3、3 SCK、4 MOSI、5 CS、6 DC、7 RST、8 BLK 预留；**不是 IPS200 模块的物理针序** |

`VM_MOTOR` 是 3S 电池的电机母线，满电约 12.6V。经开关及适当保护后，走独立功率线送两块 AT8236 的 **VM**；电机输出和功率地也走按电流选型的线、端子和转接板铜箔，**不能从 CN8/CN10 排线取电或回流**。两块模块各自的左右 `VM`、`VCC`、`GND` 针都要接到对应网络：**VM 接电机电源，VCC 接 3.3V 逻辑电源，GND 共地**。两组模块电源脚附近按芯片/小板要求加去耦与储能电容，并核对电容耐压。`3V3_LOCAL` 不与主板 CN2 的 3.3V 并联。CN8/CN10 的 7、16 脚是信号地，电机回流应走独立粗线回到电源分配点，同时保持与控制地单点/低阻共地。

## 四轮控制脚

| 电机 | 模块通道 | IN1：PWM | IN2：GPIO |
|---|---|---|---|
| 左前 FL | AT_FRONT A | PA8 / CN8-17 → AIN1 | PB13 / CN8-18 → AIN2 |
| 右前 FR | AT_FRONT B | PA9 / CN8-19 → BIN1 | PB14 / CN8-20 → BIN2 |
| 左后 RL | AT_REAR A | PA10 / CN8-21 → AIN1 | PB15 / CN8-22 → AIN2 |
| 右后 RR | AT_REAR B | PC8 / CN10-21 → BIN1 | PC11 / CN10-20 → BIN2 |

旧表的 `*_DIR` GPIO 在本版改名为 `*_IN2`；模块没有独立 DIR 或 PWM 引脚。V5 添加的 PC13、PE4、PA2、PA3 四个控制脚和 PC0/STBY **均不用接**。每个控制输入复位时应有确定低电平；先初始化 GPIO 和定时器再允许运行，必要时在板上给输入预留下拉电阻焊位。

AT8236 输入真值表：`IN1/IN2=00` 滑行/进入休眠，`10` 正向，`01` 反向，`11` 刹车。用现有一根 PWM 加一根 GPIO，令命令幅值 `d` 在 0～1：

| 命令 | IN1 | IN2 |
|---|---|---|
| 正向 | `PWM(d)` | 0 |
| 反向 | `PWM(1-d)` | 1 |
| 滑行停止 | 0 | 0 |
| 电气刹车 | 1 | 1 |

反向的 PWM 高电平区间为刹车、低电平区间才是反向驱动，因此固件需对反向占空比取反；两方向的 PWM 关断行为不同，控制参数需实测。换向先把扭矩命令降到零，用编码器确认轮速已足够低，再改变方向并渐进恢复输出；若需按电流联锁，必须另加电流检测。实际前进极性依电机接线逐轮标定。电机卖家注明不可持续堵转或带负载瞬间反转。

## 传感器与 IPS200

四路编码器 A/B：FL 用 PA6/PA7（CN8-1/-3），RL 用 PA0/PA1（CN8-2/-4），FR 用 PD12/PD13（CN10-1/-3），RR 用 PD3/PD4（CN10-2/-4）。AS5600 使用 I²C4：PC6/CN10-17 为 SCL，PC7/CN10-19 为 SDA，上拉到 `3V3_LOCAL`；PC6/PC7 也接主板步进/舵机辅助电路，须按 [V4 注意事项](双牛角座两排线方案_V4.md)检查共享负载和波形。

IPS200 使用 SPI3 单向写入：PC10/CN10-18=SCK，PC12/CN10-22=MOSI，PD11/CN10-24=CS，PD14/CN10-5=DC，PD7/CN10-6=RST。自定义 J_IPS 的背光 BLK 不默认接 3.3V，先核对实物是否带限流/需开关控制。屏幕供电规格和实际针序也须核对。参考工程在 `E:\Engineering_Training_Project\Core\Src\ips200.c` 使用 H723 的 SPI2；移植到 G474 时需改 SPI3 句柄和引脚，先低速验证 Mode 0、8 bit、MSB first，避免在平衡控制中断里整屏刷新。本仓库没有可直接烧录的 DMG474 固件。

## 模块两排针和投板核对

照片**正面、文字正立**视角下，左列从上到下为 `AOUT2, AOUT1, BIN1, BIN2, VCC, VM, GND`，右列从上到下为 `GND, VM, VCC, AIN2, AIN1, BOUT1, BOUT2`。两列各 7 针，纵向针距 2.54 mm；照片上的板外形约 23×18.5 mm，**18.5 mm 不是已确认的排针中心距**。这只是模块正面丝印顺序，转接板插座从顶视/底视绘制时可能镜像。画封装前逐脚测量 1 脚、两排中心距、插入方向、焊盘孔径，并用万用表确认 VM/GND/VCC 与模块电路的实际连通。普通 2.54 mm 排针/插座是否能承受电机和电源电流，须按所选器件额定值及实测温升确认；必要时改用额定功率连接方式。

购买页标称该小板 VM 5～17V、每路额定 3A，用户所购电机为 12V、额定 0.45A、堵转 1.3A；3S 静态电压处于标称范围，但这些数字不能证明板上排针、铜箔和散热在四轮动态工况下都足够。调试时实测起步/换向电流、驱动温升及 VM 尖峰；持续堵转与负载瞬时反转均应在控制中禁止。参考 [AT8236 芯片数据手册](https://atta.szlcsc.com/upload/public/pdf/source/20210923/1552D95CBAF8BE780D06AE79E7783380.pdf)，但模块级标称仍以所购小板及实测为准。
