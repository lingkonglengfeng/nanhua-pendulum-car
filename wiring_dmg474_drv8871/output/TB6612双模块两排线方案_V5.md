# 两片 TB6612FNG 驱动四台 12V 370 电机（V5）

> 历史方案：用户已改选 AT8236 双路模块。新制作请使用 [V6 接线方案](AT8236双模块两排线方案_V6.md)，不可沿用本版增加的四个 IN2 脚及 PC0/STBY。

用户已确认购买 **12V、空载 280 rpm** 版本；所给参数表写额定转速 220 rpm、额定电流 0.45A、堵转电流 1.3A，且注明**电机不允许堵转或带负载瞬间反转**。本版按用户选定的 **两片双路 TB6612FNG 模块**设计，一片带前轮 FL/FR，一片带后轮 RL/RR。主板到转接板仍只有 CN8、CN10 **两根 24 芯 1:1 排线**，图见 [07_TB6612双牛角座接线_V5.svg](07_TB6612双牛角座接线_V5.svg)，全网络见 [pin_assignment_v5_tb6612.csv](pin_assignment_v5_tb6612.csv)。V4 的 DRV8871 图为旧方案。

## 四个电机的控制脚

为采用 TB6612 的原生 PWM 脚，每台电机配 PWM、IN1、IN2 三根 MCU 线。原来四路 `*_PWM` 的管脚保留；原 `*_DIR` 管脚作为 IN1；新增四个空脚作 IN2。TB6612 两片的 STBY 合并，由 PC0 控制。

| 电机与模块通道 | PWM | IN1 | IN2 |
|---|---|---|---|
| 前模块 A → FL | PA8 / CN8-17 | PB13 / CN8-18 | PC13 / CN8-24 |
| 前模块 B → FR | PA9 / CN8-19 | PB14 / CN8-20 | PE4 / CN8-5 |
| 后模块 A → RL | PA10 / CN8-21 | PB15 / CN8-22 | PA2 / CN8-6 |
| 后模块 B → RR | PC8 / CN10-21 | PC11 / CN10-20 | PA3 / CN8-8 |
| 两片共用 STBY | — | PC0 / CN8-15 | 上电默认低 |

两片 STBY 连 `TB_STBY`，转接板预留 **10 kΩ 下拉到 GND**，MCU 设置输出并确认所有方向脚/定时器后才拉高。若所购 TB6612 小板已经把 STBY 硬连高电平，必须核对、处理小板电路，否则软件无法关断；不得将 MCU 的 PC0 与模块的强推高输出直接相连。所有 PWM/IN1/IN2 复位态建议有确定的低电平；必要时预留外部下拉焊位。

在 `STBY=1` 时，`IN1=1、IN2=0、PWM=d` 驱动一个方向，`IN1=0、IN2=1、PWM=d` 驱动相反方向；PWM 低电平期间进入短刹车，两个方向行为一致。`IN1=IN2=0` 为滑行停止；故障时 `STBY=0` 禁用 H 桥。**换向先把 PWM 降到 0，确认轮速/电流进入允许范围，再切换 IN1/IN2 并缓慢恢复 PWM**，遵守所购电机的禁止带负载瞬间反转说明。实际车前进时左右轮对应的 IN1/IN2 极性需逐轮标定。

## 两片模块如何接转接板

| 模块共同网络 | 连接 |
|---|---|
| VM | 3S 电池的电机母线，经电机开关、保护和独立粗线分电 |
| VCC | 转接板 `3V3_LOCAL` 逻辑电源 |
| GND | 低压信号公共地；电机电流由功率地粗线回分电点 |
| STBY | 共用 PC0 / CN8-15，10 kΩ 下拉 |
| PWMA/B、AIN1/2、BIN1/2 | 按上表各接对应网络 |
| AO1/AO2、BO1/BO2 | 分别接前/后两台电机的两根绕组线 |

转接板的模块座可以采用**每片模块两排插座/排针**，但不同商家的 TB6612 小板针序、排距和孔位可能不同。上表是电气网络，**不是可直接投板的物理针脚排列**；请用实物、背面丝印和万用表确认，再选择封装并画焊盘。若 VM 或 AO/BO 电机输出也要经过排针，还须核对触点额定电流、铜箔和散热；优先让电机电流走模块额定功率端子及独立粗线。两片模块都需要 VM、VCC、GND、STBY，不能只焊电机和三根控制信号。

CN10-23 的板载 5V 仍只送转接板本地稳压器 `U_REG`，生成 3.3V 给 TB6612 的 **VCC**、四个编码器、AS5600 和 IPS200；CN8-23 的 5V 留空。**VM 是电机电源，不与 VCC 混接。** 电机功率母线和四台电机输出都不走 CN8/CN10 或其细线排线。转接板上的本地 3.3V 不与主板 CN2-1 并联。电机母线与每片 TB6612 的 VM/GND 旁应有按模块/芯片说明配置的本地储能和去耦。

编码器、AS5600、IPS200 的接口和 CN8/CN10 分配沿用 V4。IPS200 仍用 SPI3：PC10/CN10-18=SCK、PC12/CN10-22=MOSI、PD11/CN10-24=CS、PD14/CN10-5=DC、PD7/CN10-6=RST。I²C4 为 PC6/CN10-17、PC7/CN10-19；原板的步进/舵机复用负载按 V4 说明处理。

## 电流、母线电压与验收边界

[东芝 TB6612FNG 数据手册](https://toshiba.semicon-storage.com/info/TB6612FNG_datasheet_en_20141001.pdf?did=10660&prodName=TB6612FNG)给出每通道平均 1.2A、3.2A/10ms 单次峰值，且两通道共用芯片热路径。电机参数表的 0.45A 额定电流低于此值，但 1.3A 堵转电流已超过 1.2A 平均额定。**这些规格不能证明可持续堵转，也不能证明频繁大幅度反转不会过热。** 初次调试应测两台电机同时运行时的模块温升、起步电流和换向瞬态。

东芝给出的 VM 推荐工作上限为 **13.5V**；3S 锂电满电 **12.6V**，静态余量仅 0.9V。刹车/换向时实际 VM 可能高于电池电压，须在最不利工况测主板与驱动模块附近的峰值电压，证明低于工作上限并校核所购模块电容耐压。若超限，应调整电源/驱动方案或增加经过计算和实测验证的母线过压处理；普通电容本身不保证把尖峰压到 13.5V 以下。驱动芯片的电流/热保护也不能替代电机的禁止堵转要求。

此 V5 完成接口和网络分配、SVG 图及静态冲突检查；**尚未给出与实物 TB6612 模块匹配的双排针封装，也没有 ERC/DRC 或上电测试**。这些验证取决于实际模块针序、尺寸和母线测量，不能把本图当作可直接生产的 PCB 文件。
