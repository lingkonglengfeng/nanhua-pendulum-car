# DMG474 四驱倒立摆引脚与转接板方案 V2

本方案根据资料包内 `3，原理图.zip` 的 `DMG474_V1.0.pdf` 第 2–5 页、`ATK-DMG474_V1.0 IO及接口分配表.xlsx`，以及 `DMG474硬件参考手册_V1.0.pdf` 制定。接口针号以原理图 CN8/CN10/CN2 标号为准，不以照片中的左右位置推断。逐信号表见 [pin_assignment_v2.csv](pin_assignment_v2.csv)。

## 结论

**建议做一块仅处理低压信号的汇线转接板**。DMG474 上的 CN8/CN10 是两组 2×12 针电机接口，现有四块单路 DRV8871、四个编码器和 AS5600 若各自飞线，接头多、易插错，也不利于更换电机。转接板用两个带防呆的 2×12 连接器接主板，再分出带锁扣的驱动、编码器和传感器接口。四台电机的供电、输出绕组电流走独立的保险/开关/分电端子和粗线，**不经过主板排针或这块信号板**。

这不是直接可投板的 Gerber。转接板的封装、插座性别和线序仍需按手头实物复核；模块电源/编码器电平与电机峰值电流尚未确认。

## MCU 与主板接口分配

| 轮位 | DRV8871 IN1：PWM | DRV8871 IN2：方向 | 编码器 A/B | 硬件计数器 |
|---|---|---|---|---|
| 左前 FL | PA8 / TIM1_CH1 / CN8-17 | PB13 / CN8-18 | PA6 / CN8-1，PA7 / CN8-3 | TIM3 |
| 右前 FR | PA9 / TIM1_CH2 / CN8-19 | PB14 / CN8-20 | PD12 / CN10-1，PD13 / CN10-3 | TIM4 |
| 左后 RL | PA10 / TIM1_CH3 / CN8-21 | PB15 / CN8-22 | PA0 / CN8-2，PA1 / CN8-4 | TIM5 |
| 右后 RR | PC8 / TIM8_CH3 / CN10-21 | PC10 / CN10-18 | PD3 / CN10-2，PD4 / CN10-4 | TIM2 |

TIM1 和 TIM8 均配置相同 PWM 频率；四路方向脚设普通推挽 GPIO。四组 A/B 分别配置 TIM3、TIM4、TIM5、TIM2 的编码器模式。板载 CN15 的两组编码器 A/B 与 CN8-1/3、CN10-1/3 是**同一节点**，不用重复接两次。板载 CN15 对这两组 A/B 已有 4.7 kΩ 上拉到 3.3 V 和 1 nF 对地滤波；CN8-2/4、CN10-2/4 没有这组专用滤波/上拉，转接板为后两组预留可选电阻、电容位，装配值由编码器输出类型和最高脉冲频率决定。

摆角 AS5600 使用 **PC6 / I2C4_SCL / CN10-17** 与 **PC7 / I2C4_SDA / CN10-19**；预留 IMU 可与它共用 I²C4，前提是地址不冲突。板载 EEPROM 使用 PA15/PB9 的 I²C1，因而不占用这条传感器总线。I²C4 在转接板上预留一组可装 4.7 kΩ、上拉至板载 3.3 V 的电阻，安装前检查传感器模块自身是否已上拉。

**PC6/PC7 不是完全空脚。** 原理图显示它们同时接步进控制光耦和舵机辅助电路。使用 I²C4 时，不接步进/舵机设备，不在 P7 选择或从 CN14 注入步进光耦电源；确认 PC6/PC7 空闲时高电平约 3.3 V，再做总线扫描。若实测辅助电路使总线波形不合格，应改用经验证的独立 I²C 引出方案，不直接在这两脚上加大上拉电流。AS5600 的 GH1.25-4P 实际针序仍须用模块丝印/卖家电路图确认，不能按几何图的插头朝向排线。

## 转接板接口定义

| 转接板接口 | 信号 | 连接对象 |
|---|---|---|
| J_MCU1 | CN8，2×12，全针一一对应 | DMG474 PM1 电机接口 |
| J_MCU2 | CN10，2×12，全针一一对应 | DMG474 PM2 电机接口 |
| J_PWR | 3V3_SENS、GND；CN2-1/2 | 主板低压输出 |
| J_DRV_FL/FR/RL/RR | GND、IN1(PWM)、IN2(方向) | 四块 DRV8871 的低压输入 |
| J_ENC_FL/FR/RL/RR | 3V3_SENS、GND、A、B | 四个轮组编码器；电平确认后确定供电 |
| J_AS5600 | 3V3_SENS、GND、SCL、SDA | AS5600，实际 GH 插头针序待确认 |
| J_IMU | 3V3_SENS、GND、SCL、SDA | 可选 IMU |

J_MCU1/J_MCU2 的未使用触点不得在转接板上短接；尤其主板的 5 V、控制器 3.3 V、驱动模块照片上的 `VCC` 引脚不可混接。驱动模块只用 `IN1`、`IN2`、`GND` 三个逻辑端，电机电源从单独分电端子进入其 `POWER +/−`。模块排针 `VCC` 的作用需用实物追线/测通断；此版保持悬空。

转接板建议按电源入口、接口保护、信号分配和传感器四区排布。外接编码器与 I²C 接口旁预留合适的 3.3 V ESD 保护；四个驱动信号插座旁预留下拉与串联电阻焊盘，默认输出在 MCU 复位期间保持关断。低压部分用连续地平面，驱动逻辑地只提供参考，不承载电机回流。电源由主板 CN2 的板载 3.3 V 输出供应，按手册较保守的 **1 A 可用预算**核算外部传感器总负载，不再使用原 V1 图的独立 U6 与主板 3.3 V 并联。

## 电源和固件注意点

- 原 V1 的 3S 电池、保险丝、总开关和电机开关结构仍可用；四路 DRV8871 的 `POWER +/−` 单独走分电端子。保险丝、线径和铜箔额定值应按新 370 电机的实测/厂家峰值电流确定。
- 主板 P11 默认给 CN15 编码器供电选择 5 V 或 VIN，并非 3.3 V。此方案的编码器 VCC 由 J_PWR 的 3.3 V 单独供给，CN15 的电源端不接。若编码器只能用 5 V，需核实 A/B 是否开集电极且仅上拉至 3.3 V；否则加电平转换。不可把 5 V 推挽输出直接接 MCU。
- DRV8871 的 `IN1=PWM、IN2=方向` 不是传统“PWM + DIR”真值表：正向 `IN1=PWM(d), IN2=0`；反向 `IN1=PWM(1-d), IN2=1`；零输出和故障时两输入都拉低。左右/前后电机和编码器符号分别标定。
- PWM 与方向 GPIO 上电先为安全低电平，再启动定时器；电机电源开关最后合上。固件对摆角越界、编码器无更新、控制任务超时做电机断电处理。

## 投板前必须实测/核对

1. 两组 2×12 牛角座的实物方向、1 脚、连接器性别和 24 芯排线的 1:1 线序。CN8/CN10 信号在原理图已核对，机械配合仍要测量。
2. DRV8871 小板 `VCC` 与 `POWER+` 是否同网、IN1/IN2/GND 实际排针顺序、限流电阻和所选 370 电机的堵转电流。
3. 四个编码器的供电范围、A/B 输出类型与高电平、每圈脉冲数；AS5600 圆板的 GH 针序及 3.3 V 供电能力。
4. P7/CN14 断电状态与 PC6/PC7 的上拉/低电平波形；I²C4 上拉是否与传感器板重复。
5. 主板在 300×200 mm 新底盘上的实物安装孔距、排线折弯和转接板固定空间。主板原理图外形页标注约 152.3×87.5 mm，孔中心距约 145.5×80.5 mm；转接板不应挡住 SWD、USB、电源开关。

## 本阶段验收

信号表已按原理图的 CN8/CN10/CN2、IO 分配表和 STM32G474 数据手册交叉核对：18 条 MCU 信号使用 18 个不同 GPIO；四组 A/B 对应不同定时器；PWM 与编码器定时器无冲突；未使用隔离输出端子作为原始 MCU GPIO。电源架构按主板现有 3.3 V 输出修正。

本文件是接口/转接板需求定义，尚未创建可 ERC/DRC 的电路原理图和 PCB。故 EasyEDA 设计规范的器件、网络、丝印、ERC、DRC 等 13 项投板验收目前均标记为**未执行**；在模块电气与连接器实物确认后才能形成可制造版本。
