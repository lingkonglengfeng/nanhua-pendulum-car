# AT8236 四驱转接板元器件与线缆采购清单（V6）

适用范围：ATK-DMG474 + 两块双路 AT8236 + 四台 12V 带编码器 370 电机 + AS5600 + IPS200。依据当前 [V6 接线方案](AT8236双模块两排线方案_V6.md)和 2026-09-28 的转接板原理图/PCB 截图整理。清单是**采购准备表**，不是已经通过 ERC/DRC 的最终 BOM；器件的排距、性别、针序和外形必须与实物及最终 PCB 封装一致。

## 下单与投板前必须处理

1. U1～U4 电机功率脚当前叫 `VIN_*/VOUT_*`，驱动输出叫 `*_MOTOR1/2`；网络名不一致，四路电机实际上未接通。把每台电机的两根绕组线接到对应驱动输出。
2. U6 AS5600 的 `SCL/SDA/VCC` 目前未连到 `PC6_I2C4_SCL/PC7_I2C4_SDA/3V3_LOCAL`；增加稳压器并修正网络名。编码器座当前给 5V，应先确认编码器 A/B 输出的电压与 MCU 输入兼容。
3. CN2-20 右后轮控制网应为 `PC11_RR_IN2`，不是图上的 `PC10_RR_IN2`；PC10 已作屏幕 SPI 时钟。
4. 原方案只从主控 CN10-23 取 5V 给本地稳压器，CN8-23 留空。当前图中两个 5V 针均已连接，需要按最终供电方案修正。
5. 驱动模块双排针排距、IPS 16 针接口、XH 电机插头与 XT60 极性均须按实物检查。排线防呆口方向确定后再选同向/异向；关键是逐针 1:1。完成原理图 ERC、PCB DRC 与装配干涉检查后再投板。
