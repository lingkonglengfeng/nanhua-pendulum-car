# AS5600 串口监视工具

双击 `打开实时曲线.cmd`，用桌面 Edge / Chrome 打开。更新后已打开的页面需刷新。波特率 115200，8N1，无流控。

连接串口即开始接收。v42 新增“读取 AS5600”按钮，只发送一次 `AS5600`，在停止、标定、等待顶端、运行及 `LOG 0` 时均返回最新 C/S/Q：固件版本、机械角、磁场和通信计数。查询采用控制任务持续更新的最新采样，不改变运行模式、控制参数或 LOG 开关。需先烧录 `MDK-ARM/f103_bringup/f103_bringup.hex` 的 v42 固件。

“启用日志”仍只发送 `LOG 1`、`GET`；GET 和周期日志仍仅在直立运行（state=4）或自动起摆（state=6）期间输出参数。连接本身不发送指令，页面不会自动执行 ARM、ZERO 或 SWING。

| 数据行 | 显示内容 |
|---|---|
| Q，9 列 | 原始值、机械角、STATUS、valid、MD/ML/MH |
| T，16 列；兼容旧 11 列 | 从 raw 换算机械角、顶端偏角、角速度、输出、运行状态 |
| U，18 列；兼容旧 17 列 | 最低点角度、角速度、输出、起摆阶段；支持新增 capture_deg |
| B，25 列 | 最低点角度、顶端偏角、角度有效性、标定与运行状态 |
| X，11 列 | 退出原因、冻结的原始顶端偏角、轮速峰值 |

机械角为 raw×360/4096；T/B 的顶端偏角来自固件滤波与标定，U/B 的最低点角度以最低点为零，三者分别绘制。自动选择按最新数据切换：起摆显示最低点角度，直立显示顶端偏角，单次 AS5600 查询的 Q 显示机械角；也可手动切换。

T/U 不含磁场状态或有效位，无 Q 时页面显示“未上报”，不会当成磁场正常；B 只提供角度有效性。同一 MCU 时间戳的数据合并，CSV 中未知字段留空。可点击“读取 AS5600”补充当前 Q/S。磁场区域保留最近 Q 的查询结果并明确显示该快照 MCU 时间及接收距今秒数，后续 T/U 不会抹掉它，也不会被标成新的磁场测量。若 I²C 读取失败，Q 的 raw/status 保留最后成功值，valid=0，S 错误计数增加；此时不能将保留角度当成有效新读数。STOP 按钮和手动指令仅在点击发送时执行。

支持串口助手带收发时间戳、分段换行的文本日志。内置的是保存的 v39 实际起摆日志（2026-10-18），用于查看历史记录，不代表当前连接设备或 v41 的运行结果。

