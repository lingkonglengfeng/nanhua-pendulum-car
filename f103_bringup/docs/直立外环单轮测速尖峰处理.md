## 外环速度估计修改

原来外环输入是四个有符号逻辑轮速的算术均值，单轮突跳会以1/4幅度进入车速估计，经过100ms滤波和PI改变参考角。直立场景是四轮同向平移，现改为：

```text
sorted = sort(fast_rpm[0..3])
robust_rpm = (sorted[1] + sorted[2]) / 2
outer_rpm = LP100ms(robust_rpm)
```

它剔除最大和最小的各一路，减少单路失真或打滑对车身平移估计的影响。两路或更多异常、正常轮速本来不一致的转向等情况仍可能有偏差；这不是编码器硬件故障的修复，不能以估计看起来平稳就停止检查原始数据。

以下保持：

- 编码器ISR、原始计数、20ms基础低通、轮速PI、轮位映射和符号均不改。
- 超速保护仍取四路原始基础滤波速度的最大绝对值，连续50ms超阈值仍退出；不是拿中值来放宽保护。NaN/无穷大测速仍触发原传感器故障退出。
- 原始轮速不被覆写，T.mean_rpm仍是原算术均值，便于直接观察污染；新增估计量不掩盖原始尖峰。
- 角度PID、外环增益默认值、10ms角速度滤波、BALTRIM、捕捉/退出角度、定时退出与仅ACTIVE打印策略均保持。

计算仍在5ms控制任务，固定4个栈内float做插入排序，无堆分配/阻塞；本周期估计用于下一控制周期，沿用原最多一个正常5ms周期的速度反馈时序。外环关闭时PI状态仍清零，估计值只用于诊断；它本身不会启动电机。
