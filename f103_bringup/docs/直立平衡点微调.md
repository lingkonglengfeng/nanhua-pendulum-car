# 直立平衡点微调

2026-10-18，固件0x103C8025。已编译并完成主机回归，未自动烧录、未验证实车效果。

## 实测背景与假设

06:48外环P0.038记录（附件9a610429-94d2-4125-ae44-5aad1cc63168），同零位4063/2015、内环8.4/0/0.15、外环I0、入口±0.5°、10°/s，出现明显周期摆动，后段采样角度约-1.67～+1.58°，用户确认“抖动了”；因此撤回0.035。

06:50复测0.035（附件9c37ef23-c2d6-493f-b5cf-6396d6b74f6d），同零位与其余参数确认，记录1668289～1671269ms，2.98秒。摆角采样约-0.439～+0.439°，后段多为0°或±0.088°，没有此前增长振荡形态。末均速-31.66RPM、参考-1.011°、输出-0.136、最大单轮33.11RPM，和先前0.035的末均速约-29RPM接近。角度小幅控制可短时复现，但仍缓慢漂移，不能称为长期稳摆或原地稳定。

不继续靠提高外环P来减漂移。增加一个独立手动参考角偏置，用于检验小平衡点偏差是否参与持续漂移。仅靠现有日志不能确认机械平衡点偏差是根因；该功能不是已验证的稳速修复，也不表示AS5600损坏或最低点标定失效。

## 命令及算法

```text
BALTRIM 0.10
```

参数单位°，范围-1～+1，可为小数，默认0。命令会停止当前模式、清控制历史；之后需ARM或ZERO并满足捕捉条件。所有设置仍只在RAM，复位后丢失。

```text
total_reference_deg = velocity_reference_deg + trim_deg
angle_error_rad = theta_rad - total_reference_deg * pi/180
u = BALSIGN * clamp(Kp*angle_error_rad + I_angle + Kd*rate, ±limit)
```

BALTRIM0恢复原控制公式；不改变AS5600原始读数、最低点/顶端计数、400ms捕捉和原始角度越界保护。STOP/ARM/ZERO不清除已设trim，因为它是控制配置；ZERO只重新采集传感器零点，不能把ZERO当作恢复trim的方法。设置后请保留同一标定进行比较。

配置还检查总参考范围：外环启用时max_deg+abs(trim)不得超过退出半宽的一半；关闭外环时abs(trim)也不得超过这一范围。非法范围、NaN、无穷大Watch修改会保持停机或触发配置退出。

当前BALSIGN=-1、Kp8.4时，+0.10°在其余状态相同且不饱和时使输出增加约0.01466，即向正逻辑方向偏1.47个百分点；这只是控制公式的变化，不保证实际速度一定降低，因为摆杆和车身会共同响应。首次只试+0.10，不直接用到±1°。若漂移或摆动加重，停止并撤回BALTRIM0，不同时改变PID或保护。

## 烧录后的完整设置

下载 `MDK-ARM/f103_bringup/f103_bringup.hex`。复位会丢失原参数和标定，所以先按以下顺序逐行发送，每行等OK，不能仅发BALTRIM后直接ARM：

```text
STOP
BALPID 8.4 0 0.15
BALLIMIT 70
BALSAFE 120 3000
BALWIN 0.5 20 400
BALVEL 0.035 0 3
BALSLEW 10
BALTRACE 1
BALTRIM 0.10
ZERO
```

ZERO时杆自然下垂、底盘在平整地面静止约1秒，成功后自动等待手扶顶端400ms捕捉。本次烧录必须重新ZERO，此后的同组比较只用STOP/BALTRIM/ARM，不反复标定。保留120RPM/3秒退出与原角度保护；撤驱动仍是滑行，未增加主动刹车。参数是诊断候选，尚未实车验证。

## 日志和Watch

T仍11列，error_deg仍是相对原几何顶端的角度，ref_deg仍只包含速度外环参考；不要把它当作总参考角。V尾部新增trim_deg，列数从14变15，全量协议CSV_V10；精简T协议F103_BAL_TRACE_V1保持，因为T格式和字段含义不变。

```text
V,ms,en,rpm,ref_deg,i_deg,kp,ki,limit_deg,guard_rpm,max_rpm,run_ms,max_run_ms,slew_deg_s,trim_deg
```

总参考角=V.ref_deg+V.trim_deg（对应同一时刻的T参考加该配置）。V每1秒及首次进入打印，退出后不再提交新参数；RX/ACK/HELP仍继续。Watch看g_bal_trim_deg，串口修改会在控制周期边界同时提交且先停机，更便于比较。
