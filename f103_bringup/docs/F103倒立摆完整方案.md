# F103C8T6 车载倒立摆完整实现方案（过渡平台）

> 目标：以 STM32F103C8T6（Blue Pill）为平台，完整实现选拔题全部功能：
> 摆起 → 倒立保持 20s → 抗扰 → 1.5m 正方形四顶点巡点（每点停 5s）。
> 设计原则：模块名/变量名与 G474 工程保持一致，将来回迁零障碍。

## 1. 系统组成

| 层 | 组成 |
|---|---|
| 控制器 | F103C8T6 @72MHz（HSE 8MHz × PLL9，已验证） |
| 执行 | 4× AT8236 通道（2 块双路模块）：PWM 20kHz + DIR 真值表映射 |
| 感知 | 摆杆角度 AS5600（位带 I2C，目标 200~400Hz）；4× 车轮霍尔编码器（定时器编码器模式）；航向 IMU（ICM-42688/MPU6050，强烈建议） |
| 人机 | PC13 LED（心跳/状态）；USART3 调试日志（报告数据用） |

## 2. 引脚分配（完整，最终版）

| 功能 | 引脚 | 外设/说明 |
|---|---|---|
| FL 轮 PWM | PA2 | TIM2_CH3（20kHz） |
| FR 轮 PWM | PA3 | TIM2_CH4 |
| RL 轮 PWM | PB0 | TIM3_CH3 |
| RR 轮 PWM | PB1 | TIM3_CH4 |
| FL/F** DIR ×4 | PB12~PB15 | GPIO 输出 |
| FL 编码器 A/B | PA8 / PA9 | TIM1 CH1/CH2 编码器 TI12 |
| RL 编码器 A/B | PA15 / PB3 | TIM2 CH1/CH2（部分重映射①） |
| FR 编码器 A/B | PB4 / PB5 | TIM3 CH1/CH2（部分重映射①） |
| RR 编码器 A/B | PB6 / PB7 | TIM4 CH1/CH2 |
| AS5600 + IMU SCL/SDA | PB8 / PB9 | 位带 I2C（开漏，模块 3.3V 上拉），两器件共总线（地址 0x36 / 0x68） |
| 调试串口 | PB10 / PB11 | USART3 TX/RX |
| LED | PC13 | 状态指示 |
| SWD | PA13 / PA14 | 下载调试 |

① TIM2 部分重映射（AFIO_MAPR.TIM2_REMAP=01）+ TIM3 部分重映射（=10）+ 关闭 JTAG（SWJ_CFG=010，保留 SWD）。
**原因：PA0~PA7 非 5V 容忍，编码器多为 5V 输出；重映射后编码器输入全部落在 5V 容忍(FT) 引脚上，5V/3.3V 输出都安全。**
若实测编码器输出 ≤3.3V，可用简化版：TIM2=PA0/PA1、TIM3=PA6/PA7（免重映射）。

**定时器复用技巧**：F103 只有 4 个定时器，4 路编码器占满 CH1/CH2；PWM 从 TIM2/TIM3 剩余
的 CH3/CH4 出（编码器模式下 CH3/CH4 完全空闲）。方向脚用普通 GPIO。

## 3. 关键电气检查点（上电前）

1. **编码器电平**：量编码器输出高电平（5V 还是 3.3V）→ 按上表接线（两版都安全，重映射版为默认）。
2. **共地**：Blue Pill GND ↔ 电池− ↔ 驱动模块 GND ↔ 编码器 GND ↔ AS5600/IMU GND 全部连通。
3. **供电**：VM 从电池走（只接 VM/GND）；逻辑 3.3V 从 Blue Pill 3V3；编码器 5V 从 Blue Pill 5V 针（USB 供电时可用）。
4. **电机线束**：XH6 转杜邦；电机两根功率线接模块 AOUT1/AOUT2。
5. 上电顺序：先逻辑（ST-Link/USB）→ 心跳灯闪 → 再接电池。急停习惯：测试前手边可随时拔电池。

## 5. 控制算法

### 5.1 直立环（200Hz，PD）
`u_θ = Kp·θ + Kd·θ̇` （θ：直立偏差 rad，杆顶向车头为正——沿用你们已验收的符号约定）

### 5.2 速度环（100Hz，PI 进角度给定）
`v_err = v_meas − v_ref`；`lean = Kp_v·v_err + Ki_v·∫v_err`
把 lean 叠加到角度给定（车身倾斜追速度），符号在阶段 2 实测标定。

### 5.3 转向环（100Hz，PD）
`u_ψ = Kp_ψ·(ψ_ref − ψ) + Kd_ψ·(ω_ref − ω_gyro)`

**轮输出合成**：`u_L = uθ + u_v − u_ψ`，`u_R = uθ + u_v + u_ψ` → motor_set()。

### 5.4 摆起（200Hz，能量法）
以直立为 θ=0，单位能量：`E = ½·θ̇² + (g/l)·(cosθ − 1)`（静止下垂 E=−2g/l，目标 E*=0）

```
u_a = Ke·(E* − E)·sign(θ̇·cosθ) + Kx·x + Kv·ẋ
```
前项泵能量，后两项把小车拉回原点（防漂移）。**捕捉条件**：|θ| < 20° 且 |θ̇| < 1.5 rad/s → 切直立环。
失稳（|θ| > 35°）自动回到摆起——满足"重复性"要求。

### 5.5 方形巡点（20~50Hz）
- 里程计：x, y 由 4 轮编码器（差速运动学）；航向 ψ 优先用陀螺积分（无 IMU 则用编码器差速，精度差）；
- 状态机：`待命 → 去点 k（v_ref 指向目标，ψ_ref 指向目标方向）→ 距点 <5cm → 保持 5s（位置保持 ±3~5cm）→ 下一点`；
- 起步巡点速度 ≤0.6 m/s，稳定后逐步提高（时间分）；
- 全程保持倒立：位置误差只进速度/航向环，直立环始终优先。

### 5.6 总体状态机
`上电标定(陀螺零漂) → 待命 → 摆起 → 倒立保持 →（任务使能）→ 巡点 → 完成`，
任意阶段失稳 → 自动摆起重试。启动触发用按键或串口命令。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 编码器 5V 电平伤 IO | 默认重映射方案（FT 引脚）；先测量再接线 |
| 摆起失败（机械摩擦大） | 检查摆杆枢轴/轴承顺畅度；能量法参数从慢到快调 |
| 陀螺零漂导致航向漂 | 上电静止标定；巡点每段重新对准目标方向 |
| 电池电压下降致参数漂移 | 比赛保持满电；可选加电池电压前馈 |
| AS5600 磁铁松动 | 磁铁+支架点胶固定（评分要求重复性） |
| 时间超支 | 按阶段推进，任一阶段超时先保底（保持+抗扰 50 分优先于巡点 50 分） |

## 9. 与 G474 工程的对应关系

- `as5600.c / pendulum.c` 直接沿用 G474 版逻辑（位带总线宏改 PB8/PB9）；
- `encoder/motor/control/swingup/nav/imu` 为新增模块——将来 G474 板修好后整体搬回，接口不变；
- Watch 变量沿用 `g_` 前缀命名（g_as5600_* / g_pendulum_* / g_motor_* / g_car_*），调试习惯无缝切换。
