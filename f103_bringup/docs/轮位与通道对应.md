# 本车轮位与电机通道

2026-10-18，用户逐通道测试后的最新确认；本表取代此前所有轮位记录，前后左右以用户车头定义为准。

| 电机/PWM通道 | 实际轮位 | PWM | 使用原始编码器 | 编码器引脚 |
|---|---|---|---|---|
| 0 | 右后轮，最新确认 | PA8 | 0 | PA0/PA1 |
| 1 | 右前轮，最新确认 | PA9 | 2 | PA6/PA7 |
| 2 | 左后轮，最新确认 | PA10 | 1 | PA4/PA5 |
| 3 | 左前轮，最新确认 | PA11 | 3 | PB12/PB13 |

电机索引是串口SET、LED等指令使用的通道；原始编码器索引是count/delta字段使用的采集通道，二者不要混为一谈。当前默认映射为g_enc_map={0,2,1,3}。

当前固件0x103C8019：按最新指令，将左前（电机3）和右后（电机0）相对v18取反；对应原始编码器3、0同步取反。当前g_mot_sign={-1,-1,1,1}，g_enc_sign={-1,1,-1,-1}，映射仍为{0,2,1,3}。修正同时作用于OPEN、FWD/REV及直立环。

在v18固件运行时临时修正：依次发送STOP、MOTSIGN 3 1、MOTSIGN 0 -1、ENCSIGN 3 -1、ENCSIGN 0 -1，每条末尾加换行并等待回执。新版默认已固化，串口临时设置不跨断电保存。

本表优先于此前源码、历史日志分析和旧文档中的轮位名称。此前“通道3右前”等名称作废；历史试验数据仍属于原通道，不交换通道或编码器映射。各轮正命令的车辆前进方向仍需结合实物检查。

本表记录轮位；前轮独立调参方案见 [单轮PID调试](单轮PID调试.md)。
