# 低速周期测速与转向增益

2026-10-18，固件 `0x103C8032`。用户报告零速目标时前后跑、转向困难，要求直接修改代码。新增F103混合测速、转向P默认由0.003提高到0.008；原直立8.4/0/0.17、速度外环0.038/0.0009、70%输出、差动限幅8%、±1.4°连续400ms捕捉、±25°退出和不限时设置保留。未自动烧录或运行实车。

## 下载与首轮测试

烧录 `MDK-ARM/f103_bringup/f103_bringup.hex` 或对应AXF。自然下垂且小车静止时逐行发送：

```text
STOP
BALSAFE 60 0
ZERO
```

标定完成后扶到捕捉窗口，进入ACTIVE再松手。先保持平移/转向默认目标0，记录几秒；然后单独发送 `BALTURN 5`，观察右转，发送 `BALTURN 0` 使差速目标归零。再单独测试 `BALTURN -5` 左转；不要把左右命令一次连续粘贴，否则前一方向来不及建立。停止平移目标用BALSPD0，保留直立；STOP撤驱动。

转向P0.008时，在差速测速为0且斜坡已到5RPM时，差动请求约0.04，每侧叠加正负4%占空比，旧版为1.5%。实际输出仍会受8%上限和平衡剩余余量限制。未增加转向积分或起转冲击补偿，摩擦较大时仍可能不跟踪，需要日志继续整定；不保证本版已解决长期静止或原地转向。

## 测速实现

原11线编码器A双边沿、减速21.3，输出轴468.6计数/圈不变。5ms内多1计数的原始测速步进25.61RPM，1RPM时约128ms才有一次计数。旧的20ms低通后四轮取中间两路均值，在各轮计数相位不同、脉冲稀疏时可能低估车速；加大滤波不能补出缺失信息。

在原100μs非阻塞确认后，仅使用确认通过的边沿时间戳建立周期。时间取候选边沿原始DWT时间，不取5ms任务稍后确认的时刻；短毛刺和重复IRQ不直接更新周期。ISR只做整数时间差、方向和计数，不作除法/浮点计算；跨任务/ISR的新增状态均volatile。

任务在短临界区内读取周期、方向和当前DWT时间，浮点运算在临界区外完成：

- 低于100边沿/秒（约12.8RPM）优先周期测速。
- 100～300边沿/秒（约12.8～38.4RPM）连续混合周期与5ms计数测速。
- 更高速度使用原周期计数；输出统一20ms低通。
- 首个边沿或换向后的首个边沿不能确定周期，暂用计数；连续两个同方向确认边沿后才启用周期。
- 等待下个边沿的时间超过上一周期时，以已等待时间延长周期，使测速衰减；无确认边沿250ms后使周期状态失效，再经20ms低通归零。过期会锁存，DWT回绕不会把旧速度重新激活。

这是混合测速，不是增加编码器物理分辨率。极慢速度下若每个脉冲间隔超过250ms（约低于0.51RPM），仍会退回稀疏计数；无法同时保证立即识别停转、又精确识别无限低速。反向第一次脉冲、齿轮间隙、A高低电平不均以及超过100μs的干扰仍可能影响测速。停转识别也有延迟，不能把软件处理当作零速稳定性已得到实车证明。

## 接入与日志

物理映射0右后、1右前、2左后、3左前，g_enc_map0/2/1/3及原方向不改。新增 `g_speed_estimated_rpm[4]` 按电机通道顺序保存混合测速；普通车轮速度PI、直立速度外环和差速转向使用它。前轮普通速度PI的额外60ms滤波保留；直立/转向不叠加这层滤波。原四轮中间两路融合及100ms外环低通保留。

原 `g_speed_fast[4]`、T的fast0～3和mean_rpm继续是5ms计数加20ms低通的旧测速，独立60RPM/50ms超速检查仍用它，**不因低速周期估算变平滑而放松峰值检查**。Balance_CheckMotionFeedback显式接收两组测速，并检查两组均为有限值；旧Balance_CheckMotion包装用于已有回归调用。速度保护触发、停止或故障后的转向清零逻辑保留。

T16/B25/V16/E19/P9/Y8列不变；T末尾robust_rpm和V.rpm来自新的混合测速融合，可能与T中原计数的mean_rpm不同。每100ms在P/Y附近增加：

```text
H,ms,rpm0,rpm1,rpm2,rpm3
```

H6按电机通道顺序记录混合测速，单位输出轴RPM，Watch同名g_speed_estimated_rpm。与T/P/Y一起回传便于区分真实移动、计数波动和差动输出不足。日志任务临界区一致读取H四轮，时刻与控制T快照相邻；仍只在ACTIVE打印参数。全量协议CSV_V15，精简T仍TRACE_V2。Watch的g_bal_turn_kp默认0.008，范围0～0.01。

## 验证和资源

ARMCC5全量40源警告视错编译成功；编码器、控制/运动、命令及日志回归通过。编码器测试使用生产确认器和生产任务读取包装：四轮精确周期脉冲相位错开，在5ms采样下，1/5/10RPM的四轮均值和中间两路均值均恢复相应输入值，误差限制3%；另外检查首脉冲、换向、无脉冲衰减/250ms失效、防旧周期复活、DWT回绕、混合边界以及拒绝毛刺不更新周期。控制测试确认反馈仅1RPM时，原计数测速70RPM持续50ms仍触发超速；混合测速NaN仍退出。它们是软件输入回归，不代表电机真实低速误差已小于3%。
