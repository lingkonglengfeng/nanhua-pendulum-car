# 不改线双向慢衰减PWM（0x103C8013）

用户已明确控制信号线焊死，保持现有接线，要求软件修改。原先的换线方案不再执行；g_mot_sign仍为{-1,1,1,1}，反馈映射、编码器符号、轮位定义均保持。无需把方向符号改成全-1。

## 控制方式

F103的PA8～PA11改为普通GPIO输出，与原IN2引脚PA2/PA3/PB14/PB15一起由同步DMA生成波形。每路电气正向为10驱动/11刹车，电气反向为01驱动/11刹车，零输出为00滑行。两方向都采用慢衰减，不再存在原方案一边驱动/滑行、一边驱动/刹车的模式差异。

由TIM1更新事件触发DMA1通道5向GPIOA.BSRR写入；TIM1的TRGO同时经ITR0复位TIM4，TIM4更新事件触发DMA1通道7向GPIOB.BSRR写入。TIM4的URS保持0，允许从模式控制器产生更新DMA请求。固定引脚未改变，只写电机相关GPIO位，保留编码器、AS5600、串口和LED相关位。

TIM1分频为72MHz/56，波形64个槽，PWM约20089Hz；串口TX/RX仍使用DMA1通道2/3，HAL时基仍为TIM2。资料依据：[ST RM0008的DMA请求映射、内部触发连接与URS说明](https://www.st.com/resource/en/reference_manual/rm0008-stm32f101xx-stm32f102xx-stm32f103xx-stm32f105xx-and-stm32f107xx-advanced-armbased-32bit-mcus-stmicroelectronics.pdf)、[AT8236第5页逻辑表](https://static.chipdip.ru/lib/795/DOC042795118.pdf)。

每5ms在ControlTask生成完整四轮波形，发布至两个staging bank之一；DMA中断只把完整波形复制到两个GPIO流共同空闲的循环缓冲区半区。ISR不做浮点计算、不调用RTOS或阻塞函数。发布bank/代号用极短PRIMASK区保护，防止高优先级中断看到不一致的组合。更换半区前检查两个DMA的剩余计数，至少预留32槽约25us；迟到只保留上一帧并增加诊断计数，不写DMA正在读取的半区。

单周期分辨率为1/64，在相邻5ms命令周期之间保留小数余量，使长期平均占空比接近输入值；例如10%会在6/64与7/64之间分配。具体低速表现仍需实物测试。DMA传输错误会关闭这两路波形DMA并将电机输入置00，计数暴露在M行；正常STOP也是00滑行。上电仍默认所有驱动入口关闭，没有自动起转。

实现以 `Core/Src/app_motor_dma.inc` 私有文件被app_vehicle.c包含，无需新增Keil编译源文件，避免再次出现漏加.c导致的链接错误。回退源码及12版AXF/HEX备份位于 `MDK-ARM/speed_pid_build/before_dma_motor/`。没有自动烧录。

2. 逐行发送STOP、LOG 1、OPEN 3 10，记录约3秒，STOP并等停稳。

额外测速低通仍为{0,60,0,60}ms，可通过Watch设0旁路，M/OPEN测试不由速度PID驱动。

## CSV_V5与Watch

D/C/S/W/F列数保持49/28/22/18/10。新增每次配置报告及GET返回的21列M行：

`M,ms,slow_decay,slots,pwm_hz,periods,dma_err,refill_late,isr_max_cycles,on0,in1_hi0,in2_hi0,on1,in1_hi1,in2_hi1,on2,in1_hi2,in2_hi2,on3,in1_hi3,in2_hi3`

- slow_decay=1、slots=64。on是本周期实际量化的驱动槽数，in1_hi/in2_hi是两根输入线的高电平槽数；它们不是GPIO瞬时电平，波形应用可能滞后该命令至多几个PWM周期。
- 正10%预计on3=6或7、in1_hi3=64、in2_hi3=58或57；负10%则in1_hi3与in2_hi3对换。其它三轮应全0。
- periods正常应持续增长，72MHz下每秒约20089；这是DMA循环完成计数，长时间暂停CPU造成中断合并时不能作为精确频率测量。
- dma_err正常0，refill_late正常应为0或无持续增加。isr_max_cycles/72可估算ISR最大微秒耗时；运行时序尚未上板验证，需通过M行核对，最好测量IN1/IN2波形。
- Watch对应g_motor_on_ticks、g_motor_in1_ticks、g_motor_in2_ticks、g_motor_pwm_hz、g_motor_dma_periods、g_motor_dma_errors、g_motor_dma_late、g_motor_dma_max_cycles。
- 旧D.ccr字段现在是IN1高电平占比换算至3599刻度的兼容观察量，不是TIM1的CCR；D.dir是电气方向命令，不是IN2静态引脚电平。实际波形占比以M为准，原始测试g_motor_test_pwm_pct/dir仍沿用旧命令接口，以便OPEN指令保持兼容。
