# STM32F103C8T6 引脚分配与应用详解（蓝丸 · 整车版）

> 对应工程：`f103_bringup`（固件 0x103C8003）
> 与 F407 探索者版功能完全一致：四电机 + 四 EXTI 编码器 + AS5600 + 摆角处理 + 直立环
> 本文是引脚清单、选型理由、避坑规则与扩展余量的完整说明

## 1. 芯片资源速览

- LQFP48，37 个 GPIO，64KB Flash / 20KB RAM（本项目仅用 8.6KB Flash）
- 定时器：TIM1（高级）、TIM2/3/4（通用）
- 通信：2×SPI、2×I2C、3×USART、USB、CAN
- 本项目不用硬件 I2C（AS5600 走**位带**，任意两个 IO 都行——把外设资源留给以后）

## 3. 分组详解与设计理由

### 3.1 PWM 组（PA8~PA11，TIM1 一个定时器出 4 路）

- 四路 PWM 放在**同一个定时器**：输出同频同相、寄存器同时更新——四轮驱动的加速指令天然同步，省掉跨定时器对齐的问题
- 20kHz（PSC=0、ARR=3599 @72MHz）：超出人耳，电机线圈不啸叫
- TIM1 是高级定时器：需要 MOE（`HAL_TIM_PWM_Start` 自动处理），本项目不开死区（单端驱动不需要）
- 把 4 路 PWM 集中在 PA8~PA11，是为了**把 PA0~PA7 整段留给编码器**（编码器最吃 EXTI 线号资源）

### 3.2 编码器组（EXTI 软件正交解码，2 倍频）

- **只有 A 相接中断**（双边沿），B 相普通输入——中断里读 B 电平判方向：`a≠b 则 +1，否则 -1`
- **EXTI 线号 = 引脚编号**（PA0 和 PB0 共用线 0！），所以 4 个 A 相必须落在**互不相同**的线号上：
  本项目用 **0（PA0）、4（PA4）、6（PA6）、12（PB12）** ✓
- B 相不受线号限制（不接中断），随便放
- 上拉输入：拔掉编码器时引脚不悬空
- 中断入口：`EXTI0/EXTI4/EXTI9_5（线6）/EXTI15_10（线12）` 四个处理函数（在 main.c）
- 计数速度：11 线 ×2 倍频×减速比 ≈ 每轮几百~几千计数/圈，72MHz 下 IRQ 负载 <3%
- 编码器供电：线束 **5 脚必须接 3.3V、2 脚接 GND**（血的教训：不供电=一个脉冲都没有）

### 3.3 AS5600（PB8/PB9 位带 I2C）

- 任意两个 IO 都能做位带 I2C（不占硬件外设）；选 PB8/PB9 是为了和 F407 版**引脚名相同**，两套平台接线不用改
- 开漏输出 + 模块自带 3.3V 上拉；驱动含 9 时钟总线解锁（从机卡死自恢复）
- 与 F407 版一样：5ms 读一次（200Hz），带通信/磁铁/30ms 时效三重有效性判断

### 3.4 心跳 LED（PC13）

- 蓝丸板载 LED，低电平点亮——不接调试器也能一眼看出"程序在跑"（F407 版没有这个，F103 版反而多一个优势）
- PC13 在 F103 上驱动能力弱（仅 2MHz/低驱动）：只适合 LED，别挂外设

### 3.5 调试（PA13/PA14）

- SWD 独占；工程的 `HAL_MspInit` 里调了 `SWJ_NOJTAG`——**JTAG 已禁用，PA15/PB3/PB4 已释放**（可作扩展 IO）

## 4. 避坑规则（选脚红线）

| 引脚 | 为什么避开 |
|---|---|
| **PB2** | BOOT1 启动配置脚（上电采样），当普通 IO 有启动模式风险 |
| **PC14/PC15** | 板载 32.768kHz 晶振 |
| **PD0/PD1** | 板载 8MHz 晶振（HSE） |
| **BOOT0 跳线** | 必须放"0"位——不在 0 位时上电进 Bootloader，程序"假死"（探索者上折腾一晚的同款坑） |
| PA0 的按钮 | 蓝丸 PA0 没有按钮（若是有按钮的板型，按钮=往 3.3V 短接，属无源负载，可接受） |

## 5. 空闲资源与扩展建议

### 空闲 GPIO（可用于以后加设备）

**PA12、PA15、PB0、PB1、PB3、PB4、PB5、PB6、PB7**（+ 若不做 USB 的其余脚）

| 想加什么 | 推荐引脚 | 说明 |
|---|---|---|
| 串口日志/无线 | **USART3 = PB10/PB11**（空闲） | 首选；别动 PA9/PA10 |
| IMU（ICM42688/MPU6050）| **直接挂 PB8/PB9 同一条位带 I2C** | 地址不同不冲突（0x36 vs 0x68） |
| SPI 屏/W25Q | **SPI1 重映射 = PB3/PB4/PB5** | JTAG 已禁，正好可用 |
| 备用 PWM | PB0/PB1（TIM3_CH3/4）、PB6/PB7（TIM4_CH1/2） | |
| 硬件 I2C（如果想换） | PB6/PB7（I2C1 默认脚，空闲） | 目前位带方案更稳，不刚需 |

### 定时器余量

- TIM1：已用（4 路 PWM）
- **TIM2 / TIM3 / TIM4：完全空闲**——以后做舵机/云台/双 PWM 硬件驱动的备用

|---|---|---|
| 右前 PWM | PB0 | **PA8** |
| 左前 PWM | PB1 | **PA9** |
| 右后 PWM | PE5 | **PA10** |
| 左后 PWM | PE6 | **PA11** |
| 右前 DIR | PB6 | **PA2** |
| 左前 DIR | PB7 | **PA3** |
| 右后 DIR | PB10 | **PB14** |
| 左后 DIR | PB11 | **PB15** |
