# AS5600三点中值滤波试验

2026-10-18，固件 `0x103C8027`。用户要求将滤波窗口改为3点，已编译，未自动烧录或操作电机。

角度原始采样的环形中值窗口由5点改为3点，函数更名为 `median3_circular`，保留跨4095/0的展开、排序和还原。200Hz采样下，窗口填满后的单调角度变化滞后由约2个周期（10ms）降为1个周期（5ms）。这是该中值环节的滞后，不是整个测量或控制链的总延迟；角速度低通时间常数仍为10ms。窗口变短能拒绝孤立异常样本，但对连续异常的抑制能力较弱，不能保证实车振荡一定减轻。

本次未改内外环PID、trim、轮位/方向、稳健车速估计、200Hz控制调度或原始角度退出条件；原始样本仍用于最低点标定和角度越界检查。参数仍在RAM，固件默认值仍为原先保守值，烧录复位后需重新下发试验参数。

烧录 `MDK-ARM/f103_bringup/f103_bringup.hex` 后逐行发送，每行等OK：

```text
STOP
BALPID 8.4 0 0.15
BALLIMIT 70
BALSAFE 60 5000
BALWIN 0.5 20 400
BALVEL 0.035 0.0005 3
BALSLEW 10
BALTRACE 1
BALTRIM -0.02
ZERO
```

ZERO时摆杆自然下垂、小车静止；成功后自动等待顶端连续400ms捕捉，无须立即追加ARM。保持上一轮增益和trim，只比较滤波窗口变化；重启后标定不可直接复用，需记录新B行零位。首日志应为fw=0x103C8027，V中max_run_ms=5000、trim=-0.020。参数日志仍仅在ACTIVE期间输出。

验证：抽取生产中值函数，测试启动、单调斜坡一个采样周期滞后、孤立尖峰、正反跨零和阶跃；生产角度/直立状态机/外环/保护回归通过。ARMCC5全量40个源文件构建通过，警告视为错误。Code39620、RO4144、RW696、ZI19520字节，RAM合计20216/20480字节（含预分配堆栈），ROM加载44460字节。正常Keil HEX/AXF已同步。原v26文件和固件备份在 `MDK-ARM/speed_pid_build/before_median3_v27/`。
