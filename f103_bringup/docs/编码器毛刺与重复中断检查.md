# 编码器毛刺与重复中断检查

2026-10-18，固件 `0x103C8029`。本次针对单路测速突跳增加软件输入确认与诊断，未自动烧录或操作电机。

## 本轮证据

15:46附件a202aad5-5e6f-45ae-924b-69fbe72c1771：启动约0.96秒时，T.fast3=+229.45RPM，而其它三路约0，输出-0.020；四轮算术均值被拉至+57.30RPM，但外环稳健值仍-0.01RPM、参考-0.016°。随后该路衰减至93.98、38.50RPM。用户先提到启动时可能有接触，随后明确实物轮速没有这么高、认为是检测错误。按最新观察记录为疑似测速异常；不能仅因有过接触便认定真实高速，也不能据单条日志确定是电磁干扰、接线、编码器或软件计数的哪一种根因。

当前原始A相中断入口每次收到EXTI标志即按A/B采样值加减计数，没有确认A采样值是否发生实际变化，也没有短脉冲检查。因此重复采样同一A电平的中断可能被重复计数。只读复核未发现本轮数据足以唯一确定触发该情况的物理原因。

## v29处理

- F103四路原始编码器均加入相同的非阻塞A相稳定电平确认，阈值100μs。使用已存在的DWT周期计数器计时，无等待循环和动态分配。
- A变为与已确认电平不同的状态时，保存候选时间及该边沿的B相方向。电平保持至少100μs后才更新计数；确认可由下一个真实A边沿或5ms控制任务完成。
- 100μs内返回原电平会取消这对短脉冲，两侧均不残留计数；重复采样同一A电平的IRQ不再被当作新边沿。
- 控制任务在FreeRTOS临界区内处理候选，编码器EXTI均为优先级5。读GPIO后检查EXTI待处理位；该轮若已有真实边沿排队，就交给ISR处理，避免任务先取消合法候选。
- 方向符号、原始索引到电机的映射、468.6计数/输出轴圈、20ms测速低通、三点角度中值、10ms角速度低通、现有角度/速度控制增益均未改。
- 最大单轮轮速保护仍使用确认后的四路测速最大绝对值，阈值/50ms持续判定不改，未改用稳健估计掩盖超速。

100μs小于280RPM、468.6计数/圈时约457μs的名义A相边沿间隔；主机测试覆盖该间隔的四路正反转无丢计数。这不是对实际编码器所有占空比/脉宽的硬件保证。短脉冲确认会增加计数时间延迟：连续旋转时通常到下一边沿确认，低速孤立边沿可能到下一个5ms任务周期才确认。较长的假脉冲、B相错误或接近真实正交信号的干扰仍可能通过，软件不能代替输入信号质量核查。

## E诊断行和Watch

仍仅直立ACTIVE期间打印，T16/V16/B25列和含义不变。精简协议保持TRACE_V2，增加E行，首次和每约1秒随B/V输出；全量协议为CSV_V12。GET在ACTIVE期间也包含E，非ACTIVE仍仅回执。

```text
E,ms,qualify_us,irq0,ok0,glitch0,dup0,irq1,ok1,glitch1,dup1,irq2,ok2,glitch2,dup2,irq3,ok3,glitch3,dup3
```

E共19列，四组使用**原始编码器顺序**，不是T.fast的电机顺序：

| E组 | 原始A/B输入 | 对应电机/轮位 |
| --- | --- | --- |
| 0 | PA0/PA1 | 电机0，右后 |
| 1 | PA4/PA5 | 电机2，左后 |
| 2 | PA6/PA7 | 电机1，右前 |
| 3 | PB12/PB13 | 电机3，左前 |

irq为ISR处理次数，不是示波器测到的完整物理边沿数；ok为确认计数次数（正反方向都累计为正）；glitch为取消的短脉冲/失配候选数；dup为采到相同A电平的重复IRQ数。它们从启动累计，可能存在硬件中断合并；不能简单用irq-ok减法代替glitch。每路四个数在临界区取一致值，各路由日志任务依次读取，与T的控制快照时间仅近似对应。

Watch分别为 `g_enc_irq[0..3]`、`g_enc_accepted[0..3]`、`g_enc_glitch[0..3]`、`g_enc_duplicate[0..3]`；原有带符号累计值仍看g_enc_count。

如果229RPM类型突跳消失、对应glitch/dup增长，则支持滤波拦截了该类输入；不能只凭这些计数断定硬件故障已消除。若ok仍有与实际运动不符的大幅增长，继续核查A/B波形和采样时序，不继续单凭PID增益补偿测速异常。现有网页对未知E行会忽略，原识别字段保持；本次未更改页面。

## 下载与恢复本轮候选

正常Keil HEX/AXF已更新。开机仍OFF，ZERO标定不持久化，日志仍仅ACTIVE输出。v28源码默认参数未改（外环0.037/0.0007，时限8000ms），因此下载后要恢复这轮串口候选：

```text
STOP
BALVEL 0.038 0.0009 3
BALSAFE 60 12000
ZERO
```

每行等OK。ZERO时自然下垂静止；成功后自动等待顶端400ms捕捉。不要下载后只ARM，复位会清标定。第一份日志头应为fw=0x103C8029，关注E组3，并提供完整T/B/V/E。保持原轮位和控制方向，不需要改接线来执行这轮软件测试。
