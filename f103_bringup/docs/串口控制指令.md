## 接线与格式

USART3，**115200、8N1、无流控，ASCII 文本发送，末尾加 CR、LF 或 CRLF**。命令不区分大小写，参数用空格或 Tab 分开；每条发完等待回执，再发下一条。参数可用小数或科学计数法。

| F103 | USB-TTL |
|---|---|
| PB10（TX） | RX |
| PB11（RX） | TX |
| GND | GND |

使用 3.3V TTL。板子已有供电时无需连接 USB-TTL 的供电脚。

发送使用文本模式，不选 HEX。串口助手的发送换行选项必须开启；没有行尾时，固件只保存半条命令，不会执行。

## 先测试通道 0

F103 电机方向为 `g_mot_sign={-1,-1,1,1}`；编码器方向为 `{-1,1,-1,-1}`，反馈映射为 `{0,2,1,3}`。轮位为0右后、1右前、2左后、3左前。RPM 每圈计数仍为 `11×2×21.3=468.6`。

架空车轮，依次发送下面各行，每行等待 `A,...,OK,...`：

```text
STOP
PID 0.001562 0.01 0
SET 0 60
RUN 1
```

`RUN 1` 自动退出原始单电机测试、开环直行和直立模式并进入速度环；从停止或其它模式进入时清 PID 历史。已在速度模式时重复发送保持现有积分，不会因重复使能掉速。`SET` 只改目标，不会自行开启电机。

停止时发送：

```text
STOP
```

停止命令会关闭全部电机控制入口、清零四轮目标和 PID 历史，并在该控制周期输出滑行；轮子仍可能因惯性继续转动。再次运行前需重新设置目标。

反馈方向若仍不对，先停止，确认物理轮位和前进方向后再改电机方向或编码器符号；不要在持续饱和的状态下靠增益调整修正方向问题。

## 回执和日志

每条命令由固件分配编号，成功示例：

```text
A,1,OK,SET
A,2,OK,RUN
```

成功回执表示指令已在控制周期开始时应用；它不表示机械速度已到达目标。到达情况看 D 数据行的 `rpmN/errorN` 或 PC13。

错误示例：

```text
A,3,ERR,SET,BAD_ARGS
A,4,ERR,UNKNOWN,UNKNOWN_COMMAND
```

错误原因包括 `BAD_ARGS`、`UNKNOWN_COMMAND`、`QUEUE_FULL`、`RX_OVERFLOW`、`LINE_TOO_LONG`、`BAD_CHAR`、`RX_ERROR`。非法或不完整命令不会部分修改参数。错误只丢弃命令/损坏行，不自动切换电机模式。出现接收错误后发送一个空行，再发送完整命令，以重新对齐行边界。

接收单行最多 95 个 ASCII 字符（不含行尾）。串口输入队列可容纳 8 条待执行命令，回执队列容纳 16 条；正常交互请逐条等待回执。瞬间灌入大量指令可能收到队列满或导致回执丢弃计数增加。

回执优先于周期日志；运行直立环时GET主动返回一组状态，非运行时GET只回执。HELP可在任意状态返回帮助。用于调参时保持LOG 1，保存包含B行的完整运行日志。退出后不再提交新参数包，已提交的DMA包正常发完。S行包含通信、任务栈等诊断。

## 实现与验证

TX 使用 DMA1 通道 2；RX 使用 DMA1 通道 3、512 字节循环缓冲区。低优先级任务每 5ms 服务 RX，先复制最多 256 字节再解析，避免格式化日志期间占用 DMA 接收缓冲区。USART3 接收错误中断和 DMA 中断只维护标志/计数，不解析字符串、不操作电机。

完整且合法的命令进入固定队列，200Hz ControlTask 每周期开始应用，再计算本周期反馈和输出。四轮目标与三项增益的批量设置在同一个控制周期生效。串口拔出、日志错误和接收错误均不会自动停机；停止使用显式 `STOP`。

新增 Watch：`g_uart_rx_bytes`、`g_uart_rx_overruns`、`g_uart_rx_dma_errors`、`g_uart_rx_uart_errors`、`g_uart_cmd_received`、`g_uart_cmd_applied`、`g_uart_cmd_errors`、`g_uart_cmd_reply_drops`。它们是观察量，请由固件更新。
