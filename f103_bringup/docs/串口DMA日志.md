# 四轮速度环串口 DMA 日志

最新v22（0x103C8022）为CSV_V8，新增外环V行，旧B列数不变；仅ACTIVE打印策略保留。完整解释见[10ms滤波与直立速度外环](10ms滤波与直立速度外环.md)。下方版本内容为历史记录。

v20（`0x103C8020`）行为更新：参数仅在直立环实际运行期间打印，退出后停止追加参数；标定、等待、OPEN及FWD/REV时不打印。串口接收/回执继续工作；非运行状态GET仅回执。下面有关上电/速度模式连续打印的内容为历史记录，当前行为以[直立控制说明](倒立摆串口控制与最低点标定.md)为准。

更新：当前固件为 `0x103C8015`、协议V7，新增直立环B行，默认日志100ms。原Q/D等行保持兼容。最低点标定、捕捉和参数解释见 [倒立摆串口控制与最低点标定](倒立摆串口控制与最低点标定.md)。下文旧版本的50ms/20Hz描述保留为速度环调试记录。

固件版本 `0x103C8014`。上电运行后默认打印 CSV 文本，新增 DMA 串口指令控制，见 [串口控制指令](串口控制指令.md)。默认目标 0、速度环关闭，不会因开启日志自动驱动电机。

## 接线与采集

| F103 | USB-TTL 模块 |
|---|---|
| PB10（USART3 TX） | RX |
| GND | GND |
| PB11（USART3 RX） | TX，接收文本指令 |

使用 3.3V TTL 信号。板子已有供电时，只接 TX 和 GND 即可采集日志。

串口助手设置：**115200 波特率、8 数据位、1 停止位、无校验、无流控、文本接收**。开启接收保存，保存为 `.txt` 或 `.csv`。保留全部内容，包括 `#`、`A,`、`C,`、`S,` 和 `D,` 开头的行；不要开 HEX 接收，不要只截屏。

重新下载原 Keil 工程的 AXF/HEX 并运行，Watch 确认 `g_fw_build=0x103C8014`。先保留约 2 秒静止日志，再架空测试通道 0：依次发 `STOP`、`SET 0 60`、`RUN 1`，每行等待回执，命令行末加换行。先采 5～10 秒，把日志文件发来分析。也可继续使用 Watch 控制。

此前截图存在“目标 +60、反馈负转速、输出饱和”的情况，本版已按用户反馈反转通道 0 的电机默认方向。若重新测试仍出现正目标下负转速且输出持续增大，发 `STOP` 并保留日志；先确认编码器对应和符号，再调增益。不要直接用这组未经实测的参数落地运行。

## 发送内容

控制任务仍以 5ms 周期运行；日志任务默认每 50ms 取最近一个完整控制周期快照，发送一组四轮数据。它是 20Hz 抽样日志，不是每个 5ms 周期都记录，快速振荡可能需要后续提高采样或缩小记录通道。

- `#F103_PID_CSV_V3`：协议标记。
- `#D,...`：数据列名，启动及每 5 秒重发。
- `#C,...`：参数列名，与数据列名一起重发。
- `C,...`：配置行，启动、每 1 秒以及相关参数改变后发送。
- `D,...`：数据行，默认 20 组/秒。
- `A,...`：新增指令回执；`#HELP` 为串口帮助，保留即可。
- `S,...`：通信状态，随 C 行发送，也可用 GET 获取，包含日志/RX/命令/剩余栈计数。

### D 数据行

公共列依次为 `D,ms,cycle,dt_ms,mode,speed_en,active,reached,exec_ms,missed,late,log_drop,dma_err`。

| 列 | 含义 |
|---|---|
| ms / cycle | MCU 毫秒时间 / 控制周期编号 |
| dt_ms | 当前编码器采样实际间隔，正常约 5ms |
| mode | 0 滑行、1 直立模式、2 速度环、3 开环直行、4 原始单电机测试 |
| speed_en / active | 请求开启速度环 / 实际由速度环控制 |
| reached | PC13 的速度到达状态 |
| exec_ms | 当前控制周期统计的执行时间，单位 ms；不包含后续日志快照复制 |
| missed / late | 累计漏周期 / 晚唤醒次数 |
| log_drop / dma_err | 日志忙或溢出而跳过的次数 / DMA 错误次数 |

之后按通道 0、1、2、3，每轮连续 9 列：

`targetN,rpmN,errorN,uN,iN,countN,deltaN,ccrN,dirN`

| 列 | 含义 |
|---|---|
| targetN / rpmN / errorN | 电机 N 的目标、当前速度和误差，RPM，显示两位小数 |
| uN | 速度环的限幅输出，-1～1，三位小数 |
| iN | 积分项输出，-1～1，三位小数；不是 Ki 参数 |
| countN / deltaN | 原始编码器通道 N 的累计计数 / 本次控制采样计数增量 |
| ccrN / dirN | 电机 N 实际 PWM 比较寄存器值 / DIR 引脚状态 |

`rpmN` 使用 `mapN` 对应的编码器；`countN/deltaN` 始终按原始编码器通道编号排列。若映射不是一一对应，应结合 C 行的 map 判断。计数为编码器中断更新的累计值，快照读取时与采样点可能相差少量边沿。

反向驱动采用 AT8236 的互补占空比关系，不能直接把 `ccrN/3599` 当成有符号输出；分析方向应结合 `uN`、`dirN`、`mot_signN`。

### C 配置行

包含时间、固件版本（十六进制）、Kp/Ki/Kd（六位小数）、每圈计数、主频、时钟状态、四路编码器映射、编码器符号、电机符号，以及单电机/开环/直立测试入口。列名以输出的 `#C` 行为准。配置参数、映射或方向改变时，下一个发送包会附带新 C 行。

## Watch 日志开关

| 变量 | 默认 / 含义 |
|---|---|
| `g_uart_log_enable` | 1 自动打印；改 0 停止后续日志，不改变电机状态 |
| `g_uart_log_period_ms` | 50ms；有效范围 20～1000ms，过快可能跳过日志 |
| `g_uart_log_ready` | 只读，1 表示 USART3/DMA 已初始化 |
| `g_uart_log_task_ok` | 只读，1 表示日志任务创建成功 |
| `g_uart_log_busy` | 只读，当前 DMA 正在读取发送缓冲区 |
| `g_uart_log_packets` | 只读，已完成的 DMA 发送包数，应持续增加 |
| `g_uart_log_dropped` | 只读，因忙或缓冲区溢出而跳过的日志次数 |
| `g_uart_log_dma_errors` | 只读，DMA 错误数，正常为 0 |
| `g_uart_log_dma_timeouts` | 只读，发送超时后重置日志 DMA 的次数，正常为 0 |
| `g_uart_log_stack_free_bytes` | 只读，日志任务最小剩余栈字节数 |

启动或每 5 秒附带表头的包较长，可能跨过一次 50ms 发送时刻，使 `log_drop` 少量增加；不会暂停控制任务。若持续增加，保留该计数并按默认 50ms 采集。

## 实现与验证

初始化及 DMA/USART3 中断位于 `Core/Src/app_telemetry.c`，命令解析和控制周期提交位于 `Core/Src/app_commands.c`，均加入原 Keil 工程。初始化在 `App_Init()` 最终时钟配置之后执行。PB10 为 AF 推挽，PB11 输入上拉；115200、8N1，TX DMA 普通模式，RX DMA 循环模式，字节宽度、内存递增，中断优先级 7，不调用 RTOS API。

控制任务只发布快照，低优先级 `UartLogTask` 使用 2048 字节静态任务栈和静态任务控制块；发送缓冲区为 2048 字节，使用 DMA 完成中断释放，不使用局部栈作为 DMA 数据源。格式化在临界区外，复制快照时仅短暂进入 FreeRTOS 临界区。无阻塞串口发送、无动态字符串、无 printf 浮点库；日志异常仅影响日志，不修改电机模式。

`.ioc` 仍作为现有 CubeMX 骨架使用；本模块自己配置 USART3/DMA，重新生成代码后需保留 `freertos.c` USER CODE 中的日志初始化/任务创建以及 Keil 的 `app_telemetry.c` 源文件条目，避免再生成重复的 DMA 通道 2 中断处理函数。

验证脚本 `MDK-ARM/speed_pid_build/verify_telemetry.ps1` 直接提取生产代码中的 CSV 格式化函数，使用本机 MSVC 执行回归：整数边界、浮点小数、NaN、49/28/22/18 列一致性、参数变化、缓冲区溢出检测。压力样本数据行 323 字节，平均流量上界约 6930 字节/秒，小于 115200 8N1 的 11520 字节/秒；带表头完整包 1501/2048 字节。MCU UART/DMA 和实车时序仍需下载后验证。

本版新增命令接收的回归与资源验证见 [串口控制指令](串口控制指令.md)。固件未烧录，也未测量实际运行栈余量、功耗或串口波形。

参考：[ST RM0008，USART3 默认映射及 DMA1 请求映射](https://www.st.com/resource/en/reference_manual/CD00171190-.pdf)。

新版 S 行末增加 as_ms、as_busy_skips、as_valid、as_ok、as_errors，用于检查 AS5600 调用耗时及固定 BUSY 等待问题。详见 [首轮日志分析](首轮速度环日志分析.md)。

通道1/2已根据联动日志修正默认反馈映射与编码器2符号，详见 [映射修正](通道1-2反馈映射修正.md)。

从0x103C8010起，已在速度模式时重复RUN 1保持积分历史；从停止/其它驱动模式进入仍重置。详见 [通道1实测](通道1速度环实测.md)。

本版新增W行，记录每轮实际PID及单轮覆盖状态；C行仍为共用基础值。用户已确认左前和右前实际忽快忽慢，不能仅凭累计平均速度判断前轮通过。使用PIDW单独调参，保存日志时保留W行。

0x103C8010新增PIDW单轮PID覆盖与W配置行，详见 [单轮PID调试](单轮PID调试.md)。后轮参数不变，前轮试验组尚未固化。


0x103C8011加入OPEN单轮固定输出。OPEN期间D.uN/iN为关闭的PID状态，应看ccrN/dirN判断实际输出；rpmN继续更新。详见 [右前轮固定输出对照](右前轮固定输出对照.md)。


0x103C8012协议为CSV_V4，D/C/S/W字段保持不变，每个D后增加10列F行，记录四轮额外反馈低通的有效tau与原20ms测速。前轮默认60ms，后轮旁路。需同时保存F与D用于比较，见 [前轮测速反馈滤波](前轮测速反馈滤波.md)。


0x103C8013保留焊死的全部接线和原方向符号，通过GPIO DMA把正反转都改为慢衰减，协议CSV_V5新增21列M行。旧ccr/dir字段不再代表TIM比较寄存器/静态IN2电平，第一轮先做OPEN正负10%对照，详见 [不改线双向慢衰减PWM](不改线双向慢衰减PWM.md)。


0x103C8014协议CSV_V6新增9列Q行（原始AS5600角度、度数、STATUS/valid、MD/ML/MH），每次D后发送，GET也返回。角度诊断步骤见 [AS5600角度串口诊断](AS5600角度串口诊断.md)，电机驱动和参数保持13版。
