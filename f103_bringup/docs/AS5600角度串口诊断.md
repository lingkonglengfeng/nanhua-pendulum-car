# AS5600角度串口诊断（0x103C8014）

用户已确认磁铁已经装好。最新13版速度环日志 `logs/2026-10-18_034045/` 中，AS5600读取成功计数从125471增加到130072，错误始终0，但as_valid始终0。当前证据只能确认HAL报告I2C读事务成功，尚不能确认磁场状态和角度读数有效。原日志没有raw/status，不能直接判断磁铁未检测到、过弱或过强。

当前工程本来就在200Hz ControlTask中从0x36地址读取STATUS(0x0B)及RAW_ANGLE(0x0C/0x0D)，角度换算为raw×360/4096。14版只增加串口可观察性，没有修改AS5600读取事务、磁场有效性判定、零点、摆角控制或现有电机驱动/参数。

## 新增Q行

CSV_V6保持D/C/S/W/F/M全部列数与原有含义，新增每次D之后发送的9列Q行，GET也包含Q：

`Q,ms,raw,angle_deg,status,valid,md,ml,mh`

| 字段 | 含义 |
|---|---|
| raw | AS5600原始单圈角度，0～4095 |
| angle_deg | 单圈原始机械角，0～359.912°，不是校零后的摆杆偏角 |
| status | STATUS寄存器的十进制值 |
| valid | 当前通信成功、MD=1、ML=MH=0时才为1 |
| md | bit5，检测到磁铁时为1 |
| ml | bit4，磁场过弱时为1 |
| mh | bit3，磁场过强时为1 |

例：`Q,10000,1024,90.000,32,1,1,0,0` 表示90°、磁场有效。正常状态关注 `(status & 0x38)==0x20`，不能要求其它保留位也都为0。位定义和角度寄存器依据：[ams OSRAM原厂AS5600数据手册，第18/20页](https://www.mouser.com/datasheet/2/588/AS5600_DS000365_5_00-1877365.pdf)。

通信失败时raw/status保留上一次成功读取的值，valid会清0；因此Q中的raw变化必须结合valid和S中的as_ok/as_errors判断，不能仅凭保留的角度显示认为取得了新有效样本。磁场无效时仍打印原始读数，便于诊断，不修改无效标志来强行启用控制。

## 现在怎么测

旧程序先STOP，下载14版并确认版本。逐行发送STOP、LOG 1、PERIOD 100，保持电机停止，缓慢手动转动磁铁/摆杆5～10秒，将全部日志发回。Q以10Hz打印，底层读取仍为5ms一次。先检查raw和angle_deg是否随转动变化，再结合md/ml/mh判断磁场有效性。

如果已有Watch，也可直接在13版观察g_as5600_raw_angle、g_as5600_angle_mdeg（除1000为度）、g_as5600_status、g_as5600_valid、g_as5600_read_ok、g_as5600_read_errors。无需为观察原始角度先启动电机或做零点标定。
