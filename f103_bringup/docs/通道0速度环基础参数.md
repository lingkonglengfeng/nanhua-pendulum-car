# 通道 0 速度环基础参数

当前默认参数：Kp=0.001562、Ki=0.01、Kd=0，误差单位为 RPM，积分内部乘实际 dt（秒）。固件版本 0x103C800D，通道 0 默认电机符号为 -1，其余方向和映射维持现有配置。目标和使能仍默认 0。

## 已验证范围

用户串口日志（01:59:37起，固件0x103C800C）共提取406条完整D记录，包含60RPM、100RPM、30RPM和STOP。全程采样间隔5ms，漏周期0，无速度输出饱和，串口/DMA/指令错误为0。参数在整个测试中为Kp=0.001562、Ki=0.01、Kd=0。

| 目标 | 最后2秒平均RPM | 瞬时范围 | 用同期累计计数换算RPM | 稳态平均输出 |
|---|---:|---:|---:|---:|
| 60 | 60.071 | 57.94～63.06 | 59.987 | 0.21668 |
| 100 | 100.442 | 96.71～101.82 | 99.936 | 0.35444 |
| 30 | 29.983 | 27.55～33.02 | 30.026 | 0.11298 |

60→100RPM：达到目标变化量90%约0.75s，500ms移动均值进入并保持目标±5%约1.0s。100→30RPM：对应约0.85s和1.9s。时间均相对第一条新目标记录，存在约50ms日志抽样误差。

30RPM时每5ms约1个计数，瞬时读数会有计数量化波动；累计计数的2秒平均接近30RPM。当前先保持这组增益，不为逐条瞬时读数引入微分。

STOP后的u为0，编码器速度最终降至0，指令返回OK。

## 命令使用

运行中改变目标仅发送SET，例如SET 0 100和SET 0 30，保留积分状态。再次发送PID会清积分：本轮日志536503ms附近重新发送同一组PID，导致输出短暂归零、随后恢复；该段是命令引起的清状态过程，不当作目标阶跃计算。

基础参数已经写回源码默认值并编译，当前通过串口设为同组参数的固件可继续使用；以后下载0x103C800D时复位将直接得到同组增益。
