# 直立保持5秒、直走1米、再保持5秒

固件 `0x103C8047`，2026-10-20。两段保持改为固定计时5秒，避免平衡修正导致连续稳定计时无法完成。用户实测轮径65mm、默认直行速度上限20RPM；保留v44起摆及直立/速度环参数，学生待调参副本未修改。

## 操作

上电让摆杆自然下垂，发 `ZERO`，静止等待约1秒，再发 `SWING`。起摆成功、出现T行且已松手后，发送：

```text
BALSTEP
```

收到OK后，将命令时的位置作为起点，保持5秒，然后向前走1米（速度上限20RPM），到点停稳后再保持5秒。两段5秒均按阶段进入时刻计时，期间平衡修正不会重置计时；完成后继续直立保持终点，不自动返回或关闭电机。

过程不要再发 `BALSPD 0`，它会取消本流程。`STOP`随时取消并按原逻辑撤掉驱动、退出直立。尚未进入ACTIVE时发BALSTEP返回NOT_READY，不能和SWING在未接管时一起发送。

## 距离、速度与轮径

`BALSTEP 1 20`与默认相同：相对距离1米、速度上限20RPM。支持距离-2～+2米（绝对值至少0.05米），负距离倒走；速度1～20RPM且不能超过现有轮速保护阈值的一半。保持阶段使用原位置保持速度上限，默认6RPM；行进仍按原10RPM/s斜坡及位置误差减速，不要求全程恒速。已烧录v45时可直接发`BALSTEP 1 20`使用此上限；v46可直接发`BALSTEP`。

1米换算为 `1000/(π×65)≈4.897075` 输出轴圈。目标相对于命令时的位置，保留原编码器坐标、速度积分和直立运行时限。重复BALSTEP返回BAD_ARGS，当前流程不被重启或重新锚定。

更换轮子可发 `BALWHEEL 65`，参数为有效滚动直径mm（20～300）。此配置先STOP，需重新ARM或SWING；参数只在RAM，复位恢复源码65mm。Watch为 `g_bal_wheel_diameter_mm`。若测一圈滚动距离，应除以π换算直径后设置。

## 阶段与完成条件

P行列数不变，`seq_state`及Watch的 `g_bal_seq_state`：

| 值 | 含义 |
| --- | --- |
| 7 | 起点保持，固定计时5秒 |
| 8 | 前往距离目标 |
| 9 | 终点保持，固定计时5秒 |
| 5 | 完成，继续保持终点 |
| 0 | 已取消位置序列 |

行进到点沿用原序列的停稳条件：位置误差不超过0.02输出轴圈（65mm轮约4.08mm），且整车滤波速度绝对值不超过2RPM，连续400ms后进入终点保持。只有这段到点确认需要连续满足条件；起点和终点的5秒为固定经过时间，不再受该稳定门槛限制。原有摆角、传感器、速度等退出保护保持有效。

P行 `pos_rev/goal_rev`仍为平均轮轴圈数，`stage_ms`是阶段经过时间，不是已经满足稳住条件的时间。`BALSPD`取消序列，非零`BALTURN`也取消；`BALHOLD`改为守住当前位置。原有STOP、ZERO、模式切换和故障退出保留，没有新增停机保护。

编码器里程没有绝对位置/航向反馈，轮径误差、胎压变形和打滑会影响实际1米精度，直线方向依赖现有左右差速控制。软件测试不证明当前实车已能稳住或准确走完，需要结合P/T日志复测。
