# 编码器平均里程位置保持

v37新增[原地转向模式](原地转向与零点整定.md)：BALSPIN同时运行平均里程回正和差速转向，P.seq_state6；普通BALTURN仍按旧语义取消保持。原地模式锚点取首次进入时的当前里程，重复调转速或BALSPIN0不移动锚点。此前v36捕捉自动保持、200RPM/200ms和X打印保留。

v36（0x103C8036）已改为捕捉成功自动保持进入点，窗口为180°±8°连续400ms；上电ZERO后只需扶到窗口，不再强制手动BALPZERO。详见[自动捕捉与当前位置保持](自动捕捉与当前位置保持.md)。下文v34手动启用步骤保留为历史操作方式。

当前v35（0x103C8035）更新：默认超速退出200RPM/200ms，并新增X退出诊断，见[退出诊断与200RPM阈值](退出诊断与200RPM阈值.md)。位置保持与指令不变，下文v34配置统计保留为历史说明；无需再靠Watch单独确认退出原因。

2026-10-18，固件 `0x103C8034`。按用户要求，用四轮编码器平均里程作位置反馈，位置环产生速度目标，再经现有速度外环和直立环保持倒立。新增独立位置目标/保持当前位置/当前位置置零，不必启动往返流程。已编译和主机回归，未自动烧录、未运行实车。

## 首轮操作

烧录 `MDK-ARM/f103_bringup/f103_bringup.hex` 或对应AXF后，摆杆自然下垂且小车静止，逐行发送：

```text
STOP
ZERO
```

标定完成后扶到最高点±1.4°连续400ms，进入ACTIVE并开始打印。松手后发送：

```text
BALPZERO
```

它把当前编码器平均位置设为新原点0，并立即启用位置保持。此后车偏离0时，位置误差会形成有符号速度请求，试图回到0附近。**只在需要重新定义原点时发送一次BALPZERO，不要持续重复发送，否则原点会跟着车移动，无法回正。**

如果已定义原点，想回到那个原点并保持，发送：

```text
BALPOS 0
```

两条指令不同：BALPOS0只设置目标，不修改已经累积的里程。新版本仍上电OFF、捕捉后默认零速模式，不会自行启用位置环；必须在ACTIVE时明确发送位置命令。

## 指令

| 指令 | 作用 |
| --- | --- |
| `BALPOS 0` | 目标为当前坐标系的原点，持续回正保持 |
| `BALPOS 0.1` | 目标为原点正向平均轮轴0.1圈，实际方向待实车确认 |
| `BALPOS -0.1` | 目标为原点反向0.1圈 |
| `BALHOLD` | 将当前里程作为目标，保持当前位置，不修改坐标原点 |
| `BALPZERO` | 将当前位置定义为新0，并保持目标0，不清原始编码器计数 |
| `BALPOSCFG 20 6` | 位置P增益20RPM/圈、目标速度上限6RPM，配置不主动启用保持 |
| `BALSPD 0` | 取消位置保持，改为零速度请求，继续倒立 |
| `BALTURN 5` | 取消位置保持，平移目标设0，再按原转向斜坡转向 |
| `STOP` | 取消所有控制请求并撤驱动 |

BALPOS目标范围±5圈；BALPOSCFG的Kp0.1～60、速度上限1～15RPM。位置/保持/置零仅在ACTIVE且速度外环启用时接受，否则NOT_READY；要求转向请求和斜坡目标均为0，转向尚未归零时BAD_ARGS，整条拒绝、不偷偷复位原点。先BALTURN0并等待转向斜坡归零，再启用位置保持。非法或NaN参数同样整条拒绝。

BALHOLD可以保持已累计超过±5圈的当前位置；BALPOS的±5是绝对目标输入范围，不是启动时自动把当前位置归零。大范围保持和实际回正均未验证，首轮使用BALPZERO或很小位置目标。

## 里程和控制

继续使用v30已有的真实确认计数增量：

```text
平均里程增量[轮轴圈] = (四路带符号计数增量之和) / (4 × 468.6)
目标速度[RPM] = 限幅(位置Kp × (目标圈数 − 当前圈数), ±速度上限)
```

11线编码器A双边沿、减速比21.3，因此468.6计数/输出轴圈。物理轮位和编码器原始索引不同，现有g_enc_map0/2/1/3及方向不改；四路映射为置换，平均计数的求和不受排列影响。记录的是前后方向的带符号净里程，不是各轮绝对转动距离。编码器计数本身不经低速周期估算，避免对滤波速度积分造成额外里程漂移。

位置单位为平均轮轴圈，不默认假定轮径。若测得轮径D毫米，再用 `毫米=圈数×π×D` 换算。单轮1计数对四轮平均位置的步进约0.0005335圈，显示/设定小数不增加真实分辨率。

位置P默认20RPM/圈，速度上限默认6RPM，并进一步受当前超速阈值一半限制。位置环不加积分，也不加不控制死区；以原10RPM/s速度斜坡请求速度环，速度环再调节摆角参考，直立环仍负责共同电机输出。不会同时运行单轮PI争抢平衡输出。

位置模式切换保留速度环积分、已有速度斜坡和ACTIVE运行计时。给定新位置并不瞬间清零当前速度，也不续期独立运行时限。BALPOSCFG允许ACTIVE修改，不重置目标或速度积分；它只调新的独立位置保持，原BALSEQ仍用自己的20RPM/圈与指定速度上限。

## 状态和原点

复用P行的seq_state新增5=独立位置保持；0仍手动/无位置模式，1～4仍原往返流程。不要把P.seq_state5与B.state5混淆，后者表示直立退出状态。位置保持阶段不会自动完成或切到返程，持续执行到用户取消或原有退出条件触发。

原点规则：ARM及新捕捉设位置0；BALSEQ启动也按旧规则重设自己的原点；BALPZERO明确将当前点重新设0。普通BALPOS和BALHOLD不改原点，原始g_enc_count/E累计诊断不清零。STOP和故障取消保持，保留末次里程供Watch，重新ARM后不自动恢复旧目标。ZERO仍是摆杆最低点角度标定，与BALPZERO的编码器位置原点不同。

非零转向取消独立保持及原往返流程，平移目标归0；BALTURN0不会取消正在运行的位置保持。因为这是没有航向测量的一维里程，转向后想在新位置守住，应先停转，再BALPZERO建立新局部原点；不能将转弯后的累计圈数0当成原来地面上的二维同一点。

四轮打滑、轮径差、轮胎压缩和编码器误计数都会使里程与真实地面位置不同。位置环可以给慢漂增加回正反馈，但不能承诺已解决底层速度不稳或精确锁死位置；实际会有小范围摆动，需要继续整定。±30°只是退出阈值，不是已验证都能恢复的角度。

- 当前平均位置：g_bal_position_rev。
- 目标位置：g_bal_seq_goal_rev。
- 位置模式：g_bal_seq_state=5。
- 增益/速度上限：g_bal_pos_kp、g_bal_pos_max_rpm。
- 位置环速度输出/实际斜坡：g_bal_vel_target_rpm、g_bal_vel_command_rpm。

仍只ACTIVE打印参数；P9列已有当前位置、目标位置和模式，字段不改。新增O5每约100ms输出：

```text
O,ms,kp,max_rpm,error_rev
```

error_rev为目标减当前位置，kp/max_rpm是独立保持的配置值；不是原BALSEQ的专用参数。与P/T/Y/H一起观察，日志临界区读取时刻与控制T快照相邻，不是严格同时。完整CSV_V17、精简T仍TRACE_V2，T/B/V/E/P/Y/H列数保留。发送完整日志即可，不需手工筛选。
