# F103 整车调试手册（从零到直立）

> 适用工程：`f103.2.0\f103_bringup` ｜ 固件版本 `0x103C8005`
> 核心原则：**每阶段验收通过才进下一阶段；接电池前必做电阻检测；手边随时能拔电池。**
> 配套文档：`F103引脚分配与应用.md`（接线表）、`CubeMX配置手册.md`（配置）、`FreeRTOS架构说明.md`

---

## 阶段 0 · 硬件准备（全程不接电池）

0.1 按《F103引脚分配与应用.md》逐根核对接线（换新板重插线时尤其要对照）
0.2 蓝丸 **BOOT0 跳线在 0 位**（不在位 = 上电进 bootloader 假死）
0.3 **模块离线体检**（从座上拔下、什么都不接，量模块自己的针脚）：
   - VM↔GND：表针摆动一下后回到高阻 ✓ ／ 稳定几欧～几十欧 = 模块报废
   - VM↔VCC：必须不通 ／ VCC↔GND：高阻
0.4 **插反检测**（模块插回 H 座后、接电池前必做）：
   - 量 XT60 两个焊盘（电池接口）：**高阻 ✓**；几欧～几十欧 ✗ = 模块插反或电机线圈被跨上
   - 量 XT60 第 2 脚(VM) ↔ U1~U4 线束座任意孔：**必须不通**
0.5 空板检查：XT60 两脚互不通；VM ↔ H5.1(+3.3V) 不通

**红线：VM（电池正）绝不能碰 VCC/信号脚；阶段 0 全程不接电池。**

## 阶段 1 · 烧录

## 阶段 2 · 只插 USB 上电验证（不接电池）

| Watch 变量 | 期望 | 不对时查 |
|---|---|---|
| `g_fw_build` | **0x103C8005** | 烧的不是这个固件，重新下载 |
| `g_hse_fail` | **0** | =1 见故障字典（晶振）|
| `g_clock_hz` | **72000000** | 同上 |
| `g_app_init_done` | 1 | 初始化卡住 |
| `g_rtos_heartbeat` | 持续上涨 | 不涨=程序没跑（BOOT0/复位）|

另：**PC13 灯 500ms 闪** = 调度器活着。

## 阶段 3 · 编码器验证（仍不接电池）

车架空（轮子离地），逐个手转**朝前进方向**：

| 轮位 | Watch 变量 | 期望 |
|---|---|---|
| 右前 | `g_enc_count[0]` | 计数**增加** |
| 左前 | `g_enc_count[1]` | 增加 |
| 右后 | `g_enc_count[2]` | 增加 |
| 左后 | `g_enc_count[3]` | 增加 |

（方向符号已固化 `{-1,1,-1,1}`，正常不用改）
- 某轮不动 → 查该轮线束的 **5 脚 3.3V 供电**、A/B 线
- 数字乱跳 → 检查接触/走线

## 阶段 4 · 台架电机测试（⚠ 接电池！车必须架空）

4.0 接电池前，**再把阶段 0.4 的 XT60 电阻测试做一遍**
4.1 接电池 → 两模块灯亮 → 量 VM–GND ≈ 11~12.6V
4.2 Watch 里设好后逐个测：

```
g_motor_test_wheel = 0/1/2/3    （0=右前 1=左前 2=右后 3=左后）
g_motor_test_pwm_pct = 20
g_motor_test_dir = 0
g_motor_test_enable = 1   ← 开始转
```
- 看转向：**朝车前进方向 = 正**（`g_mot_sign[i]` 保持 1）；反了 = 负
- 看完 `g_motor_test_enable = 0`，换下一个轮

4.3 四个轮测完，把方向记录发来（或自己改 `app_vehicle.c` 里 `g_mot_sign[]` 初值），重新编译烧录固化
4.4 ⚠ 永远别碰 `dir=1 且 pwm=0`（AT8236 全速反转），测完确认 enable=0

## 阶段 5 · 摆角零点标定（装好摆杆，车放平）

5.1 手扶摆杆到**直立**位置，稳 1 秒
5.2 Watch 写 `g_pendulum_zero_request = 1`
5.3 等 `g_pendulum_zero_result` 变成 **2**（成功），记下 `g_pendulum_upright_raw` 的值
5.4 让杆顶**向车头**倾斜 → `g_pendulum_angle_rad` 应变**正**；若为负：写 `g_pendulum_sign_request = -1`，再验证
5.5 把两个结果抄进 `Core\Inc\pendulum_angle_config.h`：
   - `PENDULUM_UPRIGHT_RAW` ← 记下的零点值
   - `PENDULUM_ANGLE_SIGN` ← +1 或 -1
5.6 **F7 → F8** 重新烧录。重启后核对：`g_pendulum_calibrated = 1`，缓慢摆动杆看角度连续性

## 阶段 6 · 直立环调参

6.1 **极性检查（车架空）**：Watch 设 `g_bal_kp = 2`、`g_bal_kd = 0`、`g_bal_enable = 1` → 手举摆杆**向车头轻倾** → 轮子应**朝前转**（去"追"杆）。转了反方向 → 把 kp 调成 **-2** 再验证（记下这个极性）
6.2 **加 Kp**（架空或人扶着）：2 → 4 → 6 → 8 → 10…，每档推一推杆感受"硬度"；出现高频嗡嗡抖动 → 回退一档
6.3 **加 Kd**：0.1 → 0.2 → 0.4…，抑制抖动和晃动；加太多会变"迟钝发飘"
6.4 **松手测试**（平地、人站边上、随时拔电池）：杆直立释放，能自主站住 ≥5 秒 = 入门；继续小步微调
6.5 调好后**把最终 kp/kd 固化进代码**（说一声我来改，或自己改 `app_vehicle.c` 里 `g_bal_kp/kd` 初值后重烧）

**症状-对策表：**

| 症状 | 原因 | 调法 |
|---|---|---|
| 一松手就往一边倒（不修正）| Kp 太小 / 极性反 | 加 Kp / 核对极性 |
| 高频嗡嗡抖动 | Kp 太大 / Kd 不够 | 减 Kp、加 Kd |
| 缓慢前后晃 | Kd 太大 | 减 Kd |
| 一直往一个方向跑 | 零点偏 / 机械重心偏 | 重新标定零点 |
| `g_bal_fault` 持续涨 | 摆角被判定无效 | 查磁铁/通信（阶段 2）|

**安全**：调环过程中轮子可能瞬间全油门，手别伸进轮子；杆放开测试时人站侧后方。

## 附录 B · 故障字典

| 现象 | 检查顺序 |
|---|---|
| 全灭 | 拔电池 → 重插 USB → 板子还死=被烧/稳压坏；复活后先做阶段 0.4 |
| PC13 不闪 | BOOT0 位置 → 重新烧录 → 复位 |
| 某轮不转 | IN1/IN2 信号线（对照接线表）→ 该模块通道 → 换模块验证 |
| 编码器某路不动 | 线束 5 脚 3.3V → A/B 线 → 换轮交叉验证 |
| `g_as5600_read_errors` 涨 | 磁铁未对准 → PB8/PB9 接线 → 上拉 |
| `g_hse_fail = 1` | 该板可能无 8MHz 晶振（克隆板常见）：36MHz 也能跑全部功能；或补焊晶振后免重编自动 72M |
| 车乱冲/飞车 | **立刻 `g_bal_enable=0` 或拔电池** → 查极性、零点、`g_bal_fault` |
| 编译报错 | 对比 `CubeMX骨架与回归说明.md` 的三条检查 |
