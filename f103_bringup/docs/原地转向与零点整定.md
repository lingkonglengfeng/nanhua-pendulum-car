## 原地转向指令

烧录正常Keil HEX/AXF，上电摆杆自然下垂且静止发ZERO，标定完成后扶到180°±8°连续400ms，自动倒立并保持进入点。先记录不推杆的零速段，再单独测试一个方向：

| 指令 | 请求 |
| --- | --- |
| `BALSPIN 2` | 记录当前平均里程为转向锚点，右转半轮速差目标2RPM |
| `BALSPIN -2` | 左转，保留原地转向锚点 |
| `BALSPIN 0` | 转向目标归零，继续保持同一平均里程锚点 |
| `BALTURN 0` | 差速目标归零；若处于SPIN也继续保持锚点 |
| `BALSPD 0` | 取消位置/原地转向模式，转为平移零速；转向目标仍按原BALSPD语义保留 |
| `STOP` | 撤驱动并取消全部运动请求 |

BALSPIN参数±10，与BALTURN一样是 `(左平均RPM−右平均RPM)/2`，不是转角、角速度或占空比。正值左轮比右轮快，定义为右转；实际左右与转向效果仍需实车确认。BALSPIN0不是STOP，仍保持倒立。

只在实际ACTIVE且速度外环启用时接受；否则NOT_READY。首次进入SPIN从当前里程建立新锚点，不清原始编码计数，也不改总里程的坐标原点。重复发送正/负/零转速保留同一锚点和原阶段计时，不会让位置目标追随小车漂移。它不继续追旧BALSEQ的一维返程目标；从往返切入时会取消往返并改为当前地点锚点。

P.seq_state新增6=原地转向带平均里程保持（与B.state6不存在对应关系）。位置P20产生前后纠偏请求，限幅最多6RPM；转向PI0.008/0.010负责半轮速差。两者目标绝对值之和继续不超过当前超速阈值一半且平移最多30RPM的既有余量；SPIN会按转向请求缩小前后目标上限。共同角度输出优先、差动最多12%且受80%共同限幅剩余空间约束，目标斜坡和转向反向清积分保留。

普通非零BALTURN仍取消所有位置保持，用于保留旧的手动平移/转向模式；原地需求使用BALSPIN。BALPOS/BALHOLD/BALPZERO仍要求转向请求和斜坡均归零，完成停转后才能修改位置目标。STOP/ARM/ZERO/故障取消SPIN，重新捕捉默认回普通位置保持5，不自动恢复旧转向。

这是平均净里程约束，目的是减少原地旋转时的前后窜动。它不测车体航向或地面二维位置，轮胎打滑/转向侧滑时，平均编码器位移小不等于车身中心完全不移；不保证转90°或锁住绝对地面点。位置/速度环已有漂移仍需要实车调参，新增模式不是已经验证的长期稳定结果。
