## 先测试整车前后控制

串口仍为 USART3（PB10 TX / PB11 RX），115200、8N1、无流控。文本发送，每行加 CR/LF，等待 `A,...,OK,...` 后再发下一行。最新轮位为 0右后、1右前、2左后、3左前；方向使用上述v19配置，编码器映射、双向慢衰减驱动和轮速PI保持原实现。

分别发送，下列各行是独立操作，不要整块一次发出：

| 指令 | 行为 |
|---|---|
| `FWD 30` | 四轮以 +30 RPM 前进，立即启用轮速闭环 |
| `REV 30` | 四轮以 -30 RPM 后退 |
| `MOVE -60` | 有符号速度控制，等同后退60 RPM |
| `FWD 0` / `REV 0` / `MOVE 0` | 与 STOP 相同 |
| `STOP` | 退出所有驱动模式，清目标及控制历史，输出滑行 |

`FWD/REV` 参数范围0～280，`MOVE` 为-280～280，单位为减速箱输出轴RPM。更新速度时保留已经工作的轮速PI积分；不会因重复发送同一命令每次清积分。跨入轮速模式时重新清历史。

前后指令会取消标定后的自动捕捉准备/直立模式，切入普通轮速控制。这些指令目前用于独立测试整车动力链；不表示在稳摆时给小车添加位移目标。直立环工作时，不同时叠加四个轮速PI。

前后指令持续生效直到 STOP 或切换模式。串口断开本身不会自动清除电机指令；需要停车时先发 STOP。

## 最低点标定和自动捕捉

1. 将摆杆自然垂到最低点并保持静止，发送 `ZERO`。
2. 固件关闭其它驱动模式，在200 Hz控制周期采集200个原始角度，约1秒。`A,...,OK,ZERO` 表示指令已接受；此阶段按用户要求不打印参数，可用Watch看 `g_pendulum_zero_result=2`、`g_pendulum_calibrated=1` 确认完成。标定期间运动过大或磁场/通信无效，会失败并保持停机，重新静止后再发 ZERO。
3. 标定成功后自动进入等待顶端状态。最低点定义为0°，顶端为180°；内部直立误差以顶端为0弧度。原始顶端计数为 `(bottom_raw + 2048) % 4096`，不向AS5600写零点/OTP。
4. 用手将摆杆扶到180°附近。默认捕捉窗口是 **175°～185°**，所有有效样本在窗口内保持连续400 ms，进入直立环。离开捕捉窗口、出现无效样本或超过15 ms的控制间隔，捕捉计时清零。
5. 进入后默认允许 **160°～200°**。最新未滤波角度越界、角度失效、控制间隔异常等情况，会退出直立环、清积分和输出；四轮进入滑行。滤波角度只用于PID，不用于延迟越界判定。
6. 退出后不会在摆杆回摆时自行重启。标定仍有效时发送 `ARM`，再手扶进顶端窗口400 ms；`STOP` 可以取消准备或运行。未标定时 ARM 返回 `ERR,ARM,NOT_READY`。重新上电必须重新 ZERO。

ZERO 与 STOP/RUN/FWD 等在同一批串口命令中出现时，后续停止/行驶命令会取消尚未执行的ZERO，不会迟到地重新准备直立。已经开始但被STOP取消的采样可完成标定数据，但不会自动进入等待/捕捉。

## 参数指令

| 指令 | 默认/示例 | 说明 |
|---|---|---|
| `BALPID kp ki kd` | `BALPID 1.2 0 0.08` | 直立环增益，与轮速的 PID/PIDW/KP/KI/KD 独立；更新时清直立积分 |
| `BALLIMIT pct` | `BALLIMIT 25` | 最大驱动占比25%，范围1～100%；正反对称限幅 |
| `BALWIN entry exit dwell` | `BALWIN 5 20 400` | 捕捉半宽5°、退出半宽20°、连续400 ms |
| `BALWIN 20 20 400` | 同一角度区间 | 如需捕捉和退出都使用180°±20°，可用此配置 |
| `BALSIGN +/-1` | 默认 `BALSIGN -1` | 翻转整个直立控制输出方向，不改电机/编码器映射；修改会停止，需ARM |
| `PENDSIGN +/-1` | `PENDSIGN 1` | 校正角度正方向；修改会停止，需ARM |
| `ARM` | `ARM` | 保留零点，重新等待手扶捕捉，不立即驱动电机 |
| `GET` | `GET` | 运行直立环时获取包含B行的完整状态，即使LOG=0也可用；其它状态仅回执 |
| `LOG 1` / `PERIOD 100` | 默认允许/100 ms | 仅运行直立环期间周期打印；LOG 0进一步禁用，LOG 1不会绕过运行条件 |

BALWIN的半宽范围0.1°～45°，退出半宽不得小于捕捉半宽；连续时间400～5000 ms，必须为整数。修改BALWIN会停机，之后需ARM或ZERO。参数保存在RAM，断电恢复默认。

直立环：`u = BALSIGN * clamp(Kp*theta + integral + Kd*omega, -limit, limit)`。
theta单位rad，omega单位rad/s，积分使用实际控制间隔，含抗饱和。四轮接受相同的逻辑前后命令，再经过各轮既有的电机方向修正。

**1.2 / 0 / 0.08、输出限幅25%仅为首次试验的预估值，尚未实车整定。** 当前实现的是角度稳定控制，尚无小车位置回中或自动起摆。后续根据日志调整直立参数。首次确认方向时应检查“杆顶向前偏 → 车轮向前追杆”；若相反，用STOP后更改BALSIGN，再ARM，不通过加大增益修正极性。

## 日志和Watch

协议标记升级为 `#F103_PID_CSV_V7`，原Q机械绝对角度、D轮速和其它行的列数保持不变，新增B行：

```text
B,ms,state,reason,cal,valid,zero_result,zero_samples,bottom_raw,upright_raw,bottom_deg,error_deg,rate_rad_s,u,i,kp,ki,kd,limit,entry_deg,exit_deg,dwell_ms,hold_ms,sign,angle_sign
```

| state | 含义 |
|---|---|
| 0 | 停止/未准备 |
| 1 | 最低点标定采集中 |
| 2 | 已准备，等待进入顶端窗口 |
| 3 | 顶端窗口连续计时中 |
| 4 | 直立环运行中 |
| 5 | 退出锁定，需ARM或重新ZERO |

reason：0正常，1主动停止/切到其它模式，2角度越界，3传感器或角度无效，4控制间隔异常，5标定失败/失效，6控制模式冲突，7参数无效。

zero_result：0空闲，1采集中，2成功，3样本无效，4标定期间移动，5配置错误。cal=1才可使用零点；valid表示本周期摆角有效。Q行仍是AS5600原始机械角，不会因为ZERO变成最低点0°；标定后的角度看B行bottom_deg。

Watch可看：`g_bal_state`、`g_bal_reason`、`g_bal_hold_ms`、`g_bal_enable`、`g_pendulum_bottom_deg`、`g_bal_theta`、`g_bal_theta_dot`、`g_bal_output`、`g_bal_integral`、`g_pendulum_zero_result`、`g_pendulum_zero_samples`。其中g_bal_enable由状态机生成，单独写1无法绕过400ms判定。增益可Watch修改，串口修改会在控制周期边界一起提交，更便于复现。

运行期间默认日志周期100 ms，控制仍为5 ms。每次进入运行状态立即安排列名和首条B行，之后打印完整参数；退出后不再提交新参数包，已提交的DMA包正常发完。再次ARM并满足400ms条件后自动恢复打印。列名、HELP、GET分包发送，不扩大原2 KiB DMA缓冲区。高频全量打印受115200带宽限制；先保留100 ms。请保留完整运行日志，并说明实物方向、是否松手及大致表现。退出原因可通过Watch的g_bal_reason查看。
