# 关闭轮速超限退出

固件0x103C8048起支持：

```text
BALSAFE 0 0
```

第一个0关闭由任一轮测速超过阈值连续200ms引发的SPEED退出；第二个0关闭直立总运行时限。需要先烧录v48，旧版本第一个参数不接受0。该命令沿用原行为先STOP，再重新ARM或SWING，不会在运动中悄悄改变门限。

恢复默认轮速退出门限：

```text
BALSAFE 200 0
```

非零阈值范围10～280RPM；1～9、负值、NaN、Inf仍拒绝。也可用BALSAFE 0 5000，仅关闭轮速退出、保留直立5秒运行时限。配置只在RAM生效，复位仍默认200RPM/200ms，直立运行时限默认0。

测速和峰值记录继续工作，V.max_rpm与X.max_rpm为0表示该门限已关闭，关闭时overspeed_ms归0。重新启用时从新超限开始计200ms，不继承关闭前已经累计的时长。关闭门限不会把速度目标可用范围变0，BALSPD仍±30RPM、BALSTEP行进上限仍20RPM。

这只关闭轮速超限退出；直立角度、传感器、任务时序、STOP等原行为保留。自动起摆的近顶接管仍要求轮速≤90RPM，能量起摆的15秒时限和净行程限制也不被BALSAFE 0 0关闭。

烧录会清空之前的串口RAM配置。继续前一轮新场地试调时，先重新设置SWINGCATCH 1与SWINGENERGY 0.65 64.6 0.6（尚待实测的试调组），再下垂静止ZERO、等待约1秒后SWING；源码起摆默认仍37%/.65/63.5/2rad/s/2度，没有将未验证的新场地组固化。
