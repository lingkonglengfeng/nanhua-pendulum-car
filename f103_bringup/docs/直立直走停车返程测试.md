# 直立直走、停车和返程测试

## 下载后的步骤

正常Keil输出为 `MDK-ARM/f103_bringup/f103_bringup.hex` 和 `.axf`。开机仍为OFF，目标速度0，不会自行运行轨迹。

摆杆自然下垂、小车静止时逐行发送，每行等待OK：

```text
STOP
BALSAFE 60 60000
ZERO
```

示例显式把本次试验时限设为60秒，给捕捉后下指令、停车和返程留时间；源码默认仍24秒，轮速退出阈值仍60RPM。任何运动命令都不会重置或自动延长ACTIVE总时限。试验到时或原有退出条件触发后，依旧撤驱动，不能无限期保持倒立。

标定成功后扶到最高点±1.4°内连续400ms，自动进入直立。**看到开始打印、状态ACTIVE后**发送：

```text
BALSEQ
```

默认等价于：

```text
BALSEQ 8 0.25 2000
```

含义为最大速度8RPM，前进目标为四轮平均输出轴0.25圈，停稳保持2秒，再回到这次指令记录的编码器相对原点，继续保持。若轮径65mm，0.25圈约51mm；固件直接用圈数，不依赖这个轮径假设。速度是上限，实际目标由位置误差逐渐减小，初始约5RPM，不是全程8RPM匀速。

原点在每次BALSEQ接受时重新设定，未清除原始编码器计数。重复BALSEQ会按当前所在位置重开一次流程，不续接旧原点。ZERO/ARM/STOP、普通轮速模式或任何保护退出都会取消运动请求；故障后不会自动续跑返程。

## 自动流程

| P行seq_state | 阶段 | 行为 |
| --- | --- | --- |
| 0 | 手动/无自动流程 | 按BALSPD请求或零速目标控制 |
| 1 | 直走目标点 | 位置误差产生目标RPM，幅度不超过指定上限 |
| 2 | 停车保持 | 在远端位置保持，重新满足连续停稳时间后才返程 |
| 3 | 回原点 | 位置目标设为0，按编码器里程闭环返回 |
| 4 | 原点保持 | 曾满足到位条件，继续用位置反馈保持原点 |

位置比例起点为20RPM/轮轴圈，目标速度变化率限为10RPM/s。速度外环用 `实测RPM−斜坡后的目标RPM`，仍调节摆角参考，角度PID直接控制电机；没有同时开启四个车轮速度PI来争夺电机输出。已有角度参考限幅、10°/s变化率和积分抗饱和保留，改变目标不会清空已经建立的速度PI积分。

到位条件为位置误差不超过0.02圈、外环滤波速度不超过2RPM，连续400ms。远端停车阶段要求这些条件连续满足指定的pause_ms，期间受到扰动会重新计停稳时间。到位同时检查位置与速度，不把“路过某个计数”当作停住。如果控制还没能停稳，流程会留在当前阶段等待，最终仍受总试验时限约束，不会假报已完成。

这是小范围控制试验，不是已经实车验证的导航：里程为确认后的四路带符号编码增量平均值，按468.6计数/输出轴圈换算。它不测量绝对世界位置，不补偿打滑、轮径差和车体偏航；返回的是一维编码器估计原点，不能保证二维位置严格重合。原来的零速控制还存在慢漂与慢速过冲，新目标/位置环需要用实车日志继续验证，逻辑回归不证明首次实车一定完成流程。

## 手动速度控制

```text
BALSPD 5
BALSPD 0
BALSPD -5
```

分别请求正向5RPM、零速、反向5RPM，整个过程保留直立控制。只在ACTIVE且速度外环启用时接受；否则ERR/NOT_READY。请求限制±30RPM，且不能超过当前超速退出阈值的一半；目标先经10RPM/s斜坡，不是瞬间反转。

BALSPD会取消自动流程，BALSPD0仅切换为零速度目标，不再保持旧自动原点；当前闭环尚需整定，不能把目标为0等同实际完全静止。STOP则取消所有运动模式并撤驱动，两者不同。

普通 `FWD/REV/MOVE` 保留原有轮速模式含义，仍退出直立；保持倒立的运动必须使用BALSPD/BALSEQ。

## 自定义小范围流程

```text
BALSEQ 10 0.30 1500
BALSEQ -8 0.20 2000
```

第一条最大10RPM、正向0.30圈、停稳1.5秒、返原点；第二条先反向0.20圈再正向返原点。rpm绝对值1～20，并受超速阈值一半限制；turns为正数0.05～0.5；pause_ms为400～5000的整数。无参数时使用8/0.25/2000。非法参数整条拒绝，不改变正在运行的目标。启动只在ACTIVE接受，不为未标定或等待捕捉状态偷偷启动电机。

启动时平衡控制可能先短暂向目标反方向移动以建立摆角，需结合后续轮速和P日志判断；本版仍未实车确认运动跟踪方向和位置环增益，首次只用小范围。

## 捕捉与退出角度

源码默认捕捉为最高点±1.4°连续400ms，退出为最高点±25°，即以最低点0°表示时约155°～205°。这是放宽退出窗口，窗口内PID仍持续纠偏，并没有增加“不控制”的误差死区。±25°不是已验证可恢复的推杆角度，也不保证轻推一定不倒。此前有些过坎记录只有1～3°却出现轮速增长，不能靠扩大角度退出范围处理那些速度退出或控制问题。

当前默认直立PID8.4/0/0.17，速度外环0.038/0.0009、参考限幅3°，输出70%、60RPM/50ms速度退出、24秒ACTIVE时限、BALSLEW10、trim0。示例可在ZERO前用BALSAFE60/60000显式延长本次测试；新建BALSEQ不会重置该总时限。

## 新日志和Watch

仍仅ACTIVE输出参数，T16/B25/V16/E19列保持。精简模式每约100ms增加P行，首次输出对应表头；全量协议CSV_V13，TRACE_V2的T格式不变：

```text
P,ms,target_rpm,command_rpm,error_rpm,pos_rev,goal_rev,seq_state,stage_ms
```

target是手动请求或位置控制给出的速度，command是斜坡后的目标，error为外环滤波RPM减command；位置单位均为轮轴圈。stage_ms是本阶段经过时间，不是始终满足停稳条件的时间。P由日志任务在临界区读取运动量，各字段一致，但与T的控制快照时刻近似相邻而非严格同步。

Watch：g_bal_vel_target_rpm、g_bal_vel_command_rpm、g_bal_vel_rpm、g_bal_position_rev、g_bal_seq_goal_rev、g_bal_seq_state、g_bal_seq_ms。原始g_enc_count与E累计诊断不在序列开始时清零。STOP后保留最后位置供观察，ARM/捕捉与新的BALSEQ重新设定位置原点。原点保持阶段可以持续纠偏，受到外力后当前位置仍可能短时离开容差，不能只看state4判定位置始终精确。
