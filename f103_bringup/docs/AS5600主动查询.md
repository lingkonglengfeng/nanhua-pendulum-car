# AS5600 主动查询（v42）

固件 `0x103C8042` 新增无参数串口指令：

```text
AS5600
```

115200、8N1，ASCII，末尾 CR/LF/CRLF；不区分大小写。先返回 `A,<编号>,OK,AS5600`，随后独立 DMA 包返回 C、S、Q。C 含固件版本，S 含 AS5600 成功/错误计数及读取耗时，Q 含原始计数、机械角度、STATUS、valid、MD/ML/MH。沿用原列数与字段顺序，不增加周期日志流。

指令在全部状态可用，包括停止、最低点标定、等待/捕捉顶端、直立、退出、自动起摆，以及 `LOG 0`。不要求 ZERO、ARM 或启动电机，不改变 LOG、BALTRACE、标定、使能、目标或控制输出。原 GET 及周期参数日志的运行状态条件保持原有行为。

控制任务持续以 5 ms 周期读取 AS5600，不因停止而停采样。命令通过原命令队列在控制周期边界提交；日志任务处理回执后，在后续空闲服务周期复制最新完整快照并格式化输出。查询不在 UART ISR 或日志任务另发 I²C 操作，避免与控制任务竞争总线。收到查询后的 UART DMA 忙包/回执/退出事件可能造成发送延迟；Q.ms 是快照时间，不是点击时间。一次回执批次中的多个相同查询合并成一次最新快照，正常交互逐条等待返回即可。

I²C 失败时 raw/status 为最后成功读取值，Q.valid=0，S.as_errors 反映累计读取失败。磁场正常也不代表通信成功，必须同时检查 valid。未通信成功过时默认原始值不能当成有效角度。

## 网页

`tools/as5600-monitor/as5600-monitor.html` 同步加入“读取 AS5600”按钮。连接后点击一次即可读取，即使停止或 LOG=0；自动角度选择在新 Q 到来时显示机械角，不沿用上轮直立偏角。固件旧版会返回未知指令，需先烧录新的 v42 HEX，再刷新页面。

## 验证与固件

生产命令解析及格式函数回归覆盖全部 7 种状态、LOG 0/1、大小写/CRLF、非法参数拒绝、只读状态保持、C/S/Q 序列及失败读取 valid=0；原串口 DMA/指令队列和日志格式回归通过。网页检查覆盖查询按钮仅发送 AS5600、回执、固件版本、计数和停止后机械角切换。浏览器检查使用本地串口替身，未连接实车验证。

ARMCC5 全量 40 源文件，警告视为错误，编译/链接通过。Code 47812、RO 5436、RW 828、ZI 19548 字节；链接 RAM 20376/20480 字节（含预留堆栈），压缩 ROM 加载 53416 字节。正常下载路径 `MDK-ARM/f103_bringup/f103_bringup.hex` 已同步。未烧录或驱动实车。
