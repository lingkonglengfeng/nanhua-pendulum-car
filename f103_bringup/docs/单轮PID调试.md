# 单轮独立 PID（固件 0x103C8010）

轮位已由用户确认：0左后、1左前、2右后、3右前。反馈映射为0/2/1/3。两个后轮的基础参数暂留Kp=0.001562、Ki=0.01、Kd=0；用户进一步确认左前、右前均实际忽快忽慢，前轮速度稳定性尚未通过。

右前本轮60RPM段最后2秒瞬时范围28.48～85.07RPM，累计计数平均约60.63RPM；100RPM段瞬时范围77.68～117.87RPM，累计平均约99.17RPM。平均接近目标不足以证明平稳，按用户的实物观察继续处理实际波动。

## 本轮只测右前

先STOP，等停稳后下载0x103C8010，确认串口C行或Watch版本正确，再逐行发送：

```text
PIDW 3 0.0008 0.005 0
LED 3 5
SET 3 60
RUN 1
```

架空采10～12秒，随后单独发送STOP。新组将前轮环路增益约减半，先观察实际抖动是否减轻，起转/收敛可能更慢；这只是试验组，未写成上电默认值。暂不对后轮调参。保存所有日志，包括新增W行，并反馈实物平稳程度。

## 参数选择与兼容

- `g_spd_kp/ki/kd` 仍是共用基础值，上电0.001562/0.01/0。四轮的individual默认均为0，沿用基础值。
- `PIDW <轮号> <kp> <ki> <kd>` 启用该轮独立参数，只修改该轮增益、清该轮积分/微分历史；不改其它轮参数、历史、目标或使能状态。
- `g_spd_individual[i]=1` 时使用 `g_spd_kp_w/ki_w/kd_w[i]`；为0时使用共用基础值。Watch可直接修改这些输入。
- `g_spd_kp_used/ki_used/kd_used[i]` 是本周期实际采用的增益，只读。
- 共用 `PID kp ki kd` 将四轮切回共用模式，并按原语义清四轮历史。
- 共用 `KP/KI/KD` 修改所有轮的对应单项，保留独立组中其它两项，并清四轮历史。
- Watch修改共用标量只影响当前individual=0的轮；单轮模式下修改该轮的数组值。
- STOP清目标和历史但保留RAM中的单轮设置；RUN遵循已有的重复使能保持历史规则。复位后恢复源码默认值，未写Flash。

## 日志

协议标记为CSV_V3，D/C/S仍为49/28/22列。新增18列的W行：

`W,ms,individual0,kp0,ki0,kd0,individual1,kp1,ki1,kd1,individual2,kp2,ki2,kd2,individual3,kp3,ki3,kd3`

W记录实际选取后的各轮增益。C行仍记录共用基础值，不能用C行判断已启用单轮覆盖的增益。参数改变、周期配置报告及GET都会附带W行。PIDW成功应有A回执。
