# 速度环 Watch 调参（F103 固件 0x103C8014，RPM + DMA 日志/指令）

工程保留电机引脚，F103电机到编码器默认映射为0/2/1/3，原始编码器符号为-1/1/1/-1。通道用 0/1/2/3 表示，实物轮位以你已确认的接线为准，不按旧注释重排。原先的速度 PI 扩展为 PID；默认关闭，目标均为 0。目标/当前/误差已统一为输出轴 RPM，默认增益为 Kp=0.001562、Ki=0.01、Kd=0，通道0架空30/60/100RPM已验证，其他通道及负载待测。AS5600 的有效性和摆角标定不作为速度环的启用条件。

验证：39 个源文件完整编译、链接通过，Keil Rebuild 0 Error、0 Warning；命令、测速滤波和CSV格式回归通过。此前后轮空载基础试验与5ms周期已有日志；当前前轮额外低通尚未上板验证，不能把灯或显示变平滑认定为实物调速完成。详见 [前轮测速反馈滤波](前轮测速反馈滤波.md)。

## 下载和 Watch

工程：`MDK-ARM/f103_bringup.uvprojx`。已预置 Watch 1 为速度环列表；Keil 如果正开着工程，重新打开工程以读取 `.uvoptx`，或手动添加下面的表达式。

编译产物：`MDK-ARM/speed_pid_build/f103_speed_pid.hex` 和带调试符号的 `.axf`；同时同步到原来的 `MDK-ARM/f103_bringup/f103_bringup.hex/.axf`，便于原工程下载/调试。没有自动烧录。

本机构建：`powershell -ExecutionPolicy Bypass -File .\MDK-ARM\speed_pid_build\build_speed_pid.ps1`。脚本沿用 Keil 源文件列表，使用本机 ARMCC 5，将警告当作错误。修改前的应用代码、Watch 配置和原 AXF/HEX 保存在 `MDK-ARM/speed_pid_build/backup/`。

通过硬件调试连接进入 Debug，运行程序，打开 `View → Watch Windows → Watch 1`，勾选 `View → Periodic Window Update`。点击 Value 一栏修改数值并回车；不要把 `g_spd_kp=...` 等赋值语句放进 Expression 栏。修改的是 RAM，复位、掉电或重新下载后恢复源码初值。

用户已确认：370 电机、11 线 AB 相编码器、21.3 减速比、转速 280RPM。程序仅计 A 相双边沿，因此输出轴每圈计数为 `11 × 2 × 21.3 = 468.6`，不能套用 AB 四倍频的 937.2。

换算：`RPM = 编码器计数/秒 × 60 / 468.6`。`g_enc_speed[]` 保留编码器通道的低通速度（计数/秒）；`g_speed_current[]` 是经过 `g_enc_map[]` 对应并转换后的电机反馈（RPM）。累计计数看 `g_enc_count[]`，周期增量看 `g_enc_delta[]`。读取量会由固件覆盖，应修改目标和参数。

例如旧目标 500 计数/秒约为 64.02RPM；新版本目标填 60 就是 60RPM，不要继续填 500 来测试。PID 现在直接用 RPM 误差计算。初估增益的单位换算因子为每圈计数/60（7.81）；Ki 后续根据通道0实测调到0.01。

`g_enc_counts_per_rev` 可在 Watch 校准：禁用全部电机输出，记下累计计数，沿同方向转输出轴 10 圈，再用计数变化绝对值除以 10。四轮当前共用该系数；修改后写 `g_speed_reset=1` 清历史。Watch 修改不会永久保存。

## PC13 到达目标指示

PC13 板载灯改为速度到达指示，低电平亮，原 500ms 心跳闪烁已取消；`g_rtos_heartbeat` 仍每 500ms 自增。

默认看通道 0：速度环实际工作（`g_speed_active=1`），且当前速度与非零目标的误差绝对值不超过目标绝对值的 5%，灯亮。目标 60RPM 时，当前速度在 57～63RPM 范围内点亮；目标 -60RPM 时，对应 -63～-57RPM。离开范围、目标设为 0 或退出速度模式时熄灭，不锁存。每个控制周期检查一次，不增加延时或改变电机控制。

Watch 可改 `g_speed_led_wheel=0/1/2/3` 切换观察通道，改 `g_speed_tolerance_pct` 调整容差，`g_speed_reached` 只用于观察。

## 先调通道 0

1. 架空车轮。设 `g_motor_test_enable=0`、`g_drive_test=0`、`g_bal_enable=0`、`g_speed_enable=0`，四个目标全部为 0。
2. 若使用当前基础 PI，保留默认 Kp=0.001562、Ki=0.01、Kd=0，并设 `g_speed_target[0]=60`。若从头只调 P，先把 Ki 改为 0。此时初始 P 输出约为 0.09372（9.37%），可能不足以克服静摩擦；积分会逐步增加输出。
3. 设 `g_speed_enable=1`，确认 `g_speed_active=1`。观察 `g_speed_current[0]` 和 `g_spd_u[0]`。如果反馈朝目标相反方向变化，先关速度环并核对对应编码器和方向，避免把正反馈当作增益不足。
4. 从头调参时保持 Ki、Kd 为 0，逐步增加 Kp，例如每次加 `0.0004`。让速度能跟随目标；出现明显来回波动就回退。持续 `g_spd_u[0]=1` 或 `-1` 表示已饱和，不能再靠一味增大参数解决。
5. P 大致合适后，从很小的 Ki（例如 `0.0008`）开始慢慢增加以消除稳态误差。改变 Ki 后需要等待响应；本实现的积分计算包含 dt，不要直接套用“不乘 dt”的离散 PID 参数。
6. 速度环通常先用 PI 即可。需要 D 时再从很小的值尝试；编码器量化噪声会被微分放大。这里对已经低通的速度反馈做微分，目标阶跃不会直接触发微分冲击。
7. 改目标到其它正值、0、负值，观察跟随、停止和反转。重新开始某轮试验时可写 `g_speed_reset=1`。退出速度模式或被高优先级测试接管也会清历史；Ki 改为 0 会清积分项。
8. 切换到其它通道时，先将本通道目标改为 0，再修改另一通道目标。四轮各自有独立积分和历史，共用一组参数；若以后需要逐轮独立参数，可另扩展。

其余轮目标为 0 时仍在闭环，外力转动时可能产生回正的反向输出。全部滑行请设 `g_speed_enable=0`，并保持另三个测试/直立入口为 0。运行时尽量不要暂停或单步：CPU 暂停后 PWM 外设可能仍保留输出，速度环不再更新。Watch 刷新速度远低于 200Hz，只适合先看趋势和稳态，不能据此判定很快的振荡。

## 计算方式

`error = target - current`

`P = Kp * error`

`I += Ki * error * dt`

`D = -Kd * (current - previous_current) / dt`

`output = clamp(P + I + D, -1, 1)`

I 自身限制在 ±1，输出饱和时阻止继续同方向积分，允许反方向积分退出饱和。dt 来自相邻编码器采样的实际毫秒间隔；正常任务周期是 5ms。

Watch 调好后，把 Kp/Ki/Kd 抄回 `Core/Src/app_vehicle.c` 中对应全局变量的初始化值，再编译下载才能保存。目标/使能是否改成上电自动运行，另按实际使用需求决定。

Keil Watch 操作参考：[官方 Watch Window 文档](https://www.keil.com/support/man/docs/uv4/uv4_db_dbg_watchwin.asp)。

## 串口引脚选择

本版已启用 USART3 DMA 双向通信：PB10=TX 接 USB-TTL 的 RX，PB11=RX 接 USB-TTL 的 TX，并共地，使用 3.3V TTL 信号。串口助手设 115200、8N1、无流控、文本接收，上电运行自动打印四轮 CSV 日志，默认 20 组/秒。指令需以换行结尾，可发送 `SET 0 60`、`RUN 1`、`STOP` 等控制电机，详见 [串口控制指令](串口控制指令.md) 和 [串口 DMA 日志](串口DMA日志.md)。

引脚依据：[ST RM0008，USART3_REMAP 默认 TX/PB10、RX/PB11](https://www.st.com/resource/en/reference_manual/CD00171190-.pdf)。

通道0基础参数验证结果见 [通道0速度环基础参数](通道0速度环基础参数.md)。

通道1/2已根据联动日志修正默认反馈映射与编码器2符号，详见 [映射修正](通道1-2反馈映射修正.md)。

从0x103C8010起，已在速度模式时重复RUN 1保持积分历史；从停止/其它驱动模式进入仍重置。详见 [通道1实测](通道1速度环实测.md)。

0x103C8010新增PIDW单轮PID覆盖与W配置行，详见 [单轮PID调试](单轮PID调试.md)。后轮参数不变，前轮试验组尚未固化。


## 0x103C8012 前轮反馈低通试验

新增g_speed_fast[4]保留原20ms测速，g_speed_current[4]为额外滤波后的PID反馈。g_speed_filter_ms按电机编号，上电F103为{0,60,0,60}ms；0旁路，有效值最大200，看g_speed_filter_used_ms。可以在Watch修改tau，但不要以灯更稳定代替实物观察。F日志记录原测速与tau，见 [前轮测速反馈滤波](前轮测速反馈滤波.md)。


0x103C8013保留焊死的全部接线和原方向符号，通过GPIO DMA把正反转都改为慢衰减，协议CSV_V5新增21列M行。旧ccr/dir字段不再代表TIM比较寄存器/静态IN2电平，第一轮先做OPEN正负10%对照，详见 [不改线双向慢衰减PWM](不改线双向慢衰减PWM.md)。


0x103C8014协议CSV_V6新增9列Q行（原始AS5600角度、度数、STATUS/valid、MD/ML/MH），每次D后发送，GET也返回。角度诊断步骤见 [AS5600角度串口诊断](AS5600角度串口诊断.md)，电机驱动和参数保持13版。
