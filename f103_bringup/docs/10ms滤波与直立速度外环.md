## AS5600读取与滤波

用户要求将滤波改为10ms，已将 `Core/Inc/pendulum_angle_config.h` 的 `PENDULUM_RATE_TAU_S` 从0.040改为0.010秒。它是角速度一阶低通时间常数，不是读取周期；200Hz读取和5点环形中值滤波保持原实现。

5ms采样时，角速度滤波系数从约0.111变为0.333，响应更快，同时会传入更多测速噪声。角速度由中值处理后的角度差分得出，所以10ms不代表整条测量链的总延迟；原始角度越界退出仍绕过这些滤波。

05:36附件中S行149529～150529ms，AS5600成功读取计数29906增至30106，表明该1秒区间有200次成功读取，通信错误为0。100ms是默认串口打印周期，不是AS5600读取周期。

## 新增速度外环，默认关闭

目标平均轮速为0RPM，取四轮逻辑有符号基础滤波速度均值；外环附加100ms低通。外环PI生成目标角偏置，角度PID继续直接控制四轮，不叠加四轮速度PI，不修改轮位和方向。

计算方式：

```text
v = LP100ms(mean(fast_rpm[0..3]))
Iv += Ki_v * v * dt
demand_deg = clamp(Kp_v*v + Iv, ±max_deg)
ref_deg = slew(-BALSIGN*demand_deg, 1°/s)
u = BALSIGN * clamp(Kp*(theta-ref_deg*π/180) + I_angle + Kd*omega, ±limit)
```

倒立摆速度反馈需要先改变摆杆倾斜方向，不能简单把负轮速直接叠加到电机输出。外环极性按现有逻辑速度与直立输出符号设计，并在示意小车摆模型上验证；示意模型不含本车真实质量、供电、摩擦、传动间隙和滤波全部延迟，不能证明实车稳定。外环默认关闭，以便先单独比较10ms滤波。

参考角最大±3°、变化速率1°/s；建议首次限制±2°。参考角不得超过退出半宽的一半。积分有边界、目标角/电机输出饱和时阻止继续向外积累；STOP、故障、ZERO、ARM及重新捕捉会清外环状态。全部更新在控制任务，使用实际dt，无堆分配或等待。

## 串口使用

先烧录 `MDK-ARM/f103_bringup/f103_bringup.hex`。烧录/复位后必须重新ZERO；参数不会保存在Flash。先只比较滤波，逐行发送并等OK：

```text
STOP
BALPID 7.05 0 0.205
BALLIMIT 50
BALSAFE 120 4000
BALVEL 0 0 2
ZERO
```

摆杆在最低点静止约1秒完成ZERO，再手扶到顶端连续400ms捕捉。原始角度±20°、单轮持续50ms超速、运行到时退出保护都保留；退出为滑行，不能瞬间刹停。

确认10ms滤波的地面表现后，再单独启用速度外环作下一次试验：

```text
STOP
BALVEL 0.008 0.002 2
ARM
```

这组外环参数是初估值：Kp单位°/RPM，Ki单位°/(RPM·s)，最后一项是目标角最大偏置°。速度外环命令修改会停机，需要ARM或ZERO；Kp范围0～0.05、Ki范围0～0.01、偏置范围0.1～3。两增益同时为0即关闭。角度PID的Ki仍保持0。先不要同时修改角度PID和外环增益，以便从日志判断变化来源。

## V行和Watch

协议为CSV_V8，旧B行仍25列且error_deg仍是相对物理顶端的角度，不是减去外环参考后的误差。仅在直立ACTIVE期间打印参数，新增13列V行：

```text
V,ms,en,rpm,ref_deg,i_deg,kp,ki,limit_deg,guard_rpm,max_rpm,run_ms,max_run_ms
```

其中rpm是外环100ms滤波均速，guard_rpm是超速保护用的最大单轮绝对速度；单位均RPM。ref_deg是相对顶端的参考偏置，i_deg是外环积分贡献。Watch对应 `g_bal_vel_enable`、`g_bal_vel_rpm`、`g_bal_ref_deg`、`g_bal_vel_integral_deg`、`g_bal_vel_kp`、`g_bal_vel_ki`、`g_bal_vel_limit_deg`。退出原因继续看g_bal_reason。
