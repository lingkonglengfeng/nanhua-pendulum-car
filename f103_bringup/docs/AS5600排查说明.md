本版本优先诊断 AS5600。默认 g_motor_seq_enable=0、g_motor_test_enable=0、g_bal_enable=0，复位后电机不自动运行。原四轮顺序测试仍可手动开启，当前排查不使用。

之前截图显示 heartbeat 和 read_errors 增长、read_ok=0，说明任务在执行，但未成功完成一次寄存器读取。暂不能据此判断芯片损坏，也不能将通信失败直接归因于磁铁位置。

## 先做的操作

1. 使用本版本HEX或标准Keil输出烧录、复位，确认 `g_fw_build=0x103C8007`。
2. 保持程序运行，先观察 `g_as5600_read_ok` 和 `g_as5600_read_errors`。
3. 将下列变量加入Watch。若要冻结一次完整事务的诊断结果，写 `g_as5600_poll_enable=0`，稍等任务执行；再截图。写回1继续读。

## 解释结果

`g_as5600_last_hal_status` 是HAL返回状态：0成功、1错误、2忙、3超时。

`g_as5600_last_hal_error` 是本软件I2C驱动的错误编号，不是硬件HAL I2C的位掩码：

| 错误编号 | 含义 | 下一步 |
|---|---|---|
| 0 | 最近一次读取成功 | 看原始角度是否随转动变化，再判断磁铁状态 |
| 1 | 从机未应答NACK | 结合fail_stage判断是地址阶段还是后续字节；核对供电、SCL/SDA针序、连通性和芯片型号 |
| 2 | 释放SCL后一直读不到高电平 | 暂停读数后量PB8对GND电压，检查短接、焊接、上拉及模块供电 |
| 3 | SDA持续为低或START时总线不空闲 | 暂停读数后量PB9，检查SDA短路、插反、模块断电钳位等可能原因 |

`g_as5600_bus_fail_stage`：

| 阶段编号 | 含义 |
|---|---|
| 0 | 无失败，或尚未失败 |
| 1 | 事务前总线检查 |
| 2 | 9时钟总线恢复 |
| 3 | START |
| 4 | 写地址0x6C（7位地址0x36） |
| 5 | 写寄存器地址 |
| 6 | 重复START |
| 7 | 读地址0x6D |
| 8 | 读数据 |
| 9 | STOP |

例如：`last_hal_error=1、fail_stage=4、ack_flags=0` 表示0x36写地址未获应答。两条线空闲时均高也不能证明模块已连接或供电正常，开路线被MCU内部上拉后同样会是高电平。

`g_as5600_bus_ack_flags`：bit0=写地址已应答，bit1=寄存器地址已应答，bit2=读地址已应答；完整读事务通常为7。该值在每次事务开始清零；暂停轮询后观察最清楚。

`g_as5600_scl_level/sda_level`：事务清理后的实际输入电平，暂停读数后仍刷新。正常释放的空闲总线应为1/1。`bus_idle_levels`和`bus_fail_levels`则为事务前/失败瞬间的位编码快照：bit0=SCL、bit1=SDA，3表示两线均高。

成功读取后，`raw_angle`范围为0–4095；应随磁铁转动变化。`status`的MD=bit5、ML=bit4、MH=bit3，`(status & 0x38)==0x20`表示检测到磁铁且没有过强/过弱标志。寄存器及地址依据：[ams OSRAM原厂AS5600数据手册](https://www.mouser.com/datasheet/2/588/AS5600_DS000365_5_00-1877365.pdf)。

## 接线与测量

按当前原理图应为：AS5600供电接3.3V、地接GND、SCL接PB8、SDA接PB9。核对模块实际丝印和线束针序，不只看线的颜色。

量模块端VCC对GND是否约3.3V，并核对该模块自身的供电要求。量SCL/SDA直流电平前，先将poll_enable写0；持续通信中的万用表平均值不能当作静态高低电平。

需要查通断、交换线序或插拔模块时先断电。若空闲线无法达到合适高电平，还要确认模块的上拉电阻、电源及实际波形；代码保留内部上拉作为诊断后备，不能据此保证整条总线的上升时间合格。

## 本次代码变化

- 将轮流电机测试改为默认关闭。
- 公开最近一次通信返回值、驱动错误码、失败阶段、ACK进度、线路电平和读取耗时。
- START/STOP不再忽略SCL超时；总线恢复的每个SCL高电平也检查是否真正到达。
- 失败后的STOP清理不会覆盖最先发生的错误原因。
- 增加poll_enable暂停读数，便于测量；暂停期间不增加通信成功/失败计数。
- 保留现有0x36地址、寄存器连读、PB8/PB9端口和软件时序参数，本轮不在没有测量数据时盲目提速或交换引脚。

本版本用于定位故障；通信是否恢复、实际模块电压和线路波形仍需在板上确认。
