# 新轮组选择与专用转接片

用户确认采用图片中的整套电机、支架和轮胎，不再默认前一套 520 配 30×24 L 支架。

图中可读：轮宽 27、单侧总长 85.95、支架沿电机轴向长 34、安装孔沿轴向间距 14、另一方向间距 16、4×Ø3.3。左右轮径标注存在 65/66 的疑问，暂不能确定；26.5 是图示尺寸，不据此断定电机型号。

新增小转接片 72×60×3，四角为 56×36 的 M4 接口，连接现有 FR4 底板可调槽。两条 30×3.4 槽横向中心距 16，可放入轴向间距 14 的四颗 M3 螺丝，并沿轴向调整约 ±6。四轮用四片，左右镜像放置。主底板不必先重做，原 520 四孔不再作为当前轮组直接安装孔。

推荐 FR4 或铝板加工，STL 仅供试装。沿用原转接方案的 M4 金属隔柱、螺丝连接，具体高度与 M3 长度应根据新支架厚度、轴高及螺母避让确认后定。电机轮轴高度未给出，因此没有把旧 520 的离地高度或新轮组的三维位置当成定型尺寸。

先把小片与主板固定，在小片上移动整套轮组，确保轮胎内侧与主板/转接片至少留约 3 mm，再锁紧四颗 M3 加平垫圈。垫圈要跨住槽。若这段调节行程仍不能避开轮胎，应修改小片的位置或外形，不能让轮胎擦板运行。

用户已确认购买 **12V、21.3 减速比、空载 280 rpm、带编码器**的 370 电机。参数表给出额定转速 220 rpm、额定电流 0.45A、堵转电流 1.3A，并注明不允许堵转或带负载瞬间反转。仍需编码器 A/B 接线和安装平面到轴心的高度。原 520 的 333 rpm/2.4A 数据不能套用到这套轮组；此前整车 STEP 中的 520 外形仅供旧版参考。
