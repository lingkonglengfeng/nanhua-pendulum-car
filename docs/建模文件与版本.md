# 建模文件与版本对应

模型按现有文件夹归档，尺寸单位为 mm。参数化脚本和生成文件一起保留；旧目录中有部分数据和辅助函数被新版脚本读取，不宜仅凭版本号删除。

## 主要模型入口

| 目录 | 内容 | 建议入口 / 限制 |
| --- | --- | --- |
| [pendulum_v3](../pendulum_v3/README.md) | V3 摆架、Ø32 AS5600 圆板安装结构 | `output/assembly.step` 查看装配，`output/stl/` 或 `output/3mf/` 取分件 |
| [chassis_fr4_v3_300x200](../chassis_fr4_v3_300x200/README.md) | 300 × 200 × 4 mm 底板，14 × 16 轮组直装 | `output/step/` 与 `output/dxf/`；整块底板 STL 仅作参考 |
| [pcb_bottom_adapter_v2_center](../pcb_bottom_adapter_v2_center/README.md) | 底板中央 PCB 转接件和隔柱 | `output/stl/` 打印，`output/step/` 查看装配 |
| [pendulum_rod_weight](../pendulum_rod_weight/README.md) | Ø8 铝管摆杆用可调配重 | 打印夹头与螺母；不代表后期实心铁棒的最终装配 |
| [vehicle_assembly_v1](../vehicle_assembly_v1/README.md) | 早期整车参考装配 | `output/vehicle_complete_520.step` 使用旧底盘和 520 参考轮组，不能当作比赛最终整车 |

中央 PCB 转接方案占用了旧整车模型的底部中央电池空间，二者不能在原位置直接叠装。该模型尚未包括新的电池固定方案和全部实际元件外形，详细限制见转接件 README。

## 历史版本与依赖

- `pendulum_v1/`、`pendulum_v2/`：摆架迭代。V3 的旧件兼容检查读取 V2。
- `chassis_fr4_v1/`：新版底板重建所需的几何辅助函数和孔位数据；早期整车装配也读取它。
- `chassis_fr4_v2_direct/`：320 × 220 mm 直装底板，后被 300 × 200 mm 的 V3 替代。
- `wheelset_14x16_v1/`：早期轮组转接件，V3 直装底板不再需要该过渡转接件。
- `pcb_bottom_adapter_v1/`：早期 PCB 安装方式，V2 改为底板中央安装。
- `wiring_dmg474_drv8871/`：文件夹名沿用最初方案，内部包含多次驱动与接线迭代，属于 G474 历史资料；F103 当前接口见 [固件说明](../f103_bringup/README.md)。

根目录 `HARDWARE_SELECTION.md` 是 2026-09-28 的历史选型记录，其中的 G474 主控、摆杆和整车描述不等同于后期 F103 实物。

## 打开文件

- **STEP**：用于 CAD 查看、结构修改及装配参考；完整装配文件不用于整件打印。
- **STL / 3MF**：使用分件目录中的输出。3MF 未必包含打印机或材料配置，仍需在切片软件检查。
- **DXF**：用于底板轮廓和孔位；加工前查看对应版本说明中的单位、厚度和材料。
- **HTML / PNG / SVG**：离线预览和尺寸示意；不能根据屏幕截图比例直接加工。

例如 [V3 摆架预览图](../pendulum_v3/output/preview/assembly.png) 和 [V3 底板孔位图](../chassis_fr4_v3_300x200/output/preview/chassis_V3_top.png) 可先用于了解结构。作者提供的 [整车实物照片](images/car-overview.jpg) 与 [底部安装照片](images/car-underside.jpg) 已单独归档；照片用于了解实际装配，不替代尺寸图或模型版本说明。

## 重新生成模型

只查看成品不需要 Python 环境。重建主要依赖 CadQuery、trimesh、numpy、matplotlib；底板脚本还使用 ezdxf 和 resvg_py。摆架已有 [`requirements.txt`](../pendulum_v3/requirements.txt)，其他子项目的依赖尚未合并成统一安装文件。

在仓库根目录准备好环境后，模型入口为：

```powershell
python .\pendulum_v3\build_model.py
python .\pendulum_v3\check_exports.py
python .\pendulum_v3\verify_v3.py
python .\chassis_fr4_v3_300x200\build_direct.py
python .\pendulum_rod_weight\build_weight.py
python .\pcb_bottom_adapter_v2_center\build_adapter.py
```

这些脚本会重新写入各自的输出文件。三维 HTML 的重建使用对应的 `build_viewer.py`，早期整车装配使用 `vehicle_assembly_v1/build_vehicle.py`。部分旧说明中的 `D:/blance_car/.cad-venv/` 是原作者本机环境路径，在其他电脑上替换成自己的 Python 环境。

模型已有的几何检查结果用于说明设计文件的状态，不代表所有零件已完成实物加工、强度或比赛验证。后期摆杆、传感器和主控变化，以补充的实物记录为准。
