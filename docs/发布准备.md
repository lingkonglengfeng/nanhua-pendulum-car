# GitHub 发布整理记录

首次公开整理包含项目首页、F103 使用入口、建模版本导航、技术调试过程初稿，以及根据作者口述整理的个人复盘、自制转接板工程、原理图及两张实物照片。仓库名为 `lingkonglengfeng/nanhua-pendulum-car`，默认分支为 `main`。

## 已整理的范围

- 当前 `f103_bringup/` 固件、随工程提供的 HAL / CMSIS / FreeRTOS、串口工具。
- 摆架、底盘、转接件、配重和参考整车的建模源文件及输出。
- 现有技术调试文档及面向读者的新导航。
- `hardware/adapter-board/` 保存作者提供的原始硬件工程和原理图；已注明设计仍有纰漏，实物使用飞线修正。
- `docs/images/` 保存整车及底部接线的两张实物照片。
- `.gitignore` 排除厂商整套资料盘、早期 G474 固件、重复归档、虚拟环境、生成缓存、调试器个人布局和批量原始日志。本地文件仍保留。
- 保留 `speed_pid_build/` 里的构建/验证脚本和测试源文件；只排除其中备份、主机生成目录与编译输出。
