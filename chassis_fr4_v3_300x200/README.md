# 底板 V3 300×200×4 mm

按已确认的图片预览生成正式三维底板及 DXF。此版替代 320×220 的 V2；原版本保留作历史。当前轮组为 370、280 转、带编码器的整套，四孔间距沿车前后 X 为 16、沿电机轴向 Y 为 14。

## 文件

- `output/step/chassis_V3_direct_14x16_300x200x4.step`：三维实体，适合 CAD 编辑与加工报价。
- `output/dxf/chassis_V3_direct_14x16_300x200x4.dxf`：毫米实尺寸的切割/钻孔轮廓，厚度 4 mm。
- `output/stl_reference/chassis_V3_direct_14x16_300x200x4.stl`：封闭网格。底板不能整体放进 A1 mini；该文件可用于查看或试排版。
- `output/preview/chassis_V3_top.svg/png`：孔位查看图，不能按截图比例打孔。
- `output/hole_coordinates_mm.csv`：以板中心为原点的孔位表。

## 这次的调整

底板长 300、宽 200、厚 4，四角 R10。倒立摆底座的八个 M5 孔不变，两个底座占地 160×190，前后各余 70、左右各余 5。

轮组孔组中心从 Y=±94 改为 ±84，每侧内移 10。每组四个 Ø3.4 孔，中心在 X=±118，对应实际孔 X=±110/±126、Y=±77/±91。

前后传感器槽从 X=±150 改为 ±140。原侧边八个扩展孔移到 X=±140、Y=±60/±85，以免底座遮挡。前后 36 个板卡孔、中央 IMU 四孔、电池四槽、走线两槽保留。总计 84 个孔/槽。

推荐无覆铜 FR4 加工，穿透螺丝配垫圈与螺母，不在板上攻承力螺纹。数量一块。加工前核对材料、单位和厚度，不要使用旧版 DXF。

## 检查与未定项目

已检查单实体有效性、封闭 STL、DXF 回读、孔槽无交叠、边缘余量、原底座与新轮组孔距；结果见 `verification.json`。

电机安装面到轴心高度仍未知，所以此文件确认的是底板，不代表新轮组整车高度已经定型。先用实物检查轮胎、支架与板边间隙。ATK-DMG474 主板外形约 152×87.5，端部安装空间较紧，需核对实际孔距、架高与插头空间，不能直接当作已经匹配的专用主控孔阵。未做实物刚度或控制试验。

再生成需同级 `chassis_fr4_v1` 的几何辅助函数和 `pendulum_v3` 的底座 STEP；独立查看/加工本版成品文件不需要它们。
