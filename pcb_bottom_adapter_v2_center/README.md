# V2：电路板居中安装，连接底盘中部四个长条槽

本版按用户修正设计：电路板位于底板正下方中央，连接中部四个原有长条槽，槽中心距 **80×60 mm**。PCB 外形 **90×70 mm**，四孔中心距 **84×64 mm**，使用 **M3**。

读取 V3 300×200×4 mm 底盘 STEP，保留原底盘几何。电路板沿车长 X 为 70、沿车宽 Y 为 90；孔距对应 X 为 64、Y 为 84。孔阵按 PCB 中心对称处理，孔中心距板边 3 mm。PCB 厚度仅暂按 1.6 mm 建模。

## 文件

- `output/stl/01_adapter_center_84x64_M3.stl`：转接板打印 **1 件**，80×60 车架连接孔阵，64×84 PCB 孔阵。
- `output/stl/02_spacer_D8_H10_M3_qty4.stl`：隔柱打印 **4 件**，外径 8、高 10、通孔 Ø3.4。
- `output/step/01_adapter_center_84x64_M3.step`：可编辑转接板实体。
- `output/step/03_center_chassis_adapter_pcb_assembly.step`：中央装配，含原底盘、原摆架底座、转接板、PCB 参考体和简化紧固件。不是整件打印文件。
- `output/preview/adapter_viewer.html`：离线可旋转预览，默认显示中央装配。
- `output/preview/adapter_and_assembly.png`：打印件与中央安装效果。
- `output/preview/dimensions.svg/png`：尺寸图，灰色虚线表示底盘原有槽孔投影。
- `output/hole_coordinates_mm.csv`：以底盘中心为原点的孔位表。
- `output/adapter_profile_reference.dxf`：平面轮廓参考，BOSS_REFERENCE 为辅助层；立体支柱以 STEP 为准。
- `output/verification.json`：几何检查结果与已知限制。

## 主要尺寸

底盘上表面 Z=0，下表面 Z=-4；两个板件的平面中心均在 **(0,0)**。

| 项目 | 尺寸 / 坐标 mm |
|---|---|
| 转接板外形 | 100×104，外角 R5 |
| 转接板主板厚度 | 4 |
| 四个一体 PCB 支柱 | 增高 6，接触面 Ø5.5，根部 Ø9 锥形加强 |
| 打印件整体高度 | 10 |
| 中央开窗 | 44×64，R5 |
| PCB 孔 | X=±32、Y=±42，4×Ø3.4 |
| 连接底盘的孔 | X=±40、Y=±30，4×Ø3.4 |
| 底盘原槽 | 18×3.5，长边沿 X；槽中心 X=±40、Y=±30 |
| 底盘与转接板之间 | 四个 Ø8×10 通孔隔柱 |
| 转接板主板 Z 范围 | -18 至 -14 |
| PCB 朝向底盘的表面 | Z=-24 |
| PCB 外侧表面 | Z=-25.6（板厚暂按 1.6） |
| PCB 螺丝头最低点 | 约 Z=-29.1 |

转接板为圆孔，M3 螺丝穿过原底盘长槽的中点。长槽提供沿 X 的对位余量；安装时以两板中心对齐为准。转接板连接螺丝在 PCB 两侧，底部垫圈与 PCB 板边名义间隙 1.5 mm，可从下方装卸。

## 采购与装配

| 配件 | 数量 | 用途 |
|---|---:|---|
| M3×25 螺丝 | 4 | 从底盘顶部穿过垫圈、4 mm 底盘、10 mm 隔柱、4 mm 转接板 |
| M3 大垫圈，外径 9、厚约 0.5 | 4 | 底盘上表面跨住宽 3.5 的槽 |
| M3 普通垫圈，外径约 7、厚约 0.5 | 4 | 转接板下侧螺母处 |
| M3×16 螺丝 | 4 | 从 PCB 外侧穿过 PCB、一体支柱和转接板 |
| M3 小外径绝缘垫圈，外径约 5.5 | 4 | PCB 螺丝头处 |
| M3 螺母 | 8 | 两组紧固 |

顶部 Ø9 垫圈在槽宽方向每侧搭接 **2.75 mm**；底部 Ø8 隔柱每侧搭接 **2.25 mm**。顶部垫圈距原摆架底座最近 **0.5 mm**，请采用指定外径，避免随意换成更大的垫圈。紧固件长度基于上述板厚与垫圈厚度，实际叠层改变时调整长度。

1. 转接板平整大面朝打印平台，一体支柱朝上；隔柱竖直打印。建议 PETG、0.2 mm 层高、4 圈壁、约 35% 填充，此方向无需悬空支撑。
2. 清理 Ø3.4 通孔，使 M3 螺丝自由穿过；使用穿透螺丝配螺母，不在打印孔内直接攻螺纹。
3. 先将 PCB 固定到四个一体支柱下方；PCB 朝底盘的一面与转接板之间留 6 mm。PCB 安装孔周围需有足够无元件区域，螺母及螺丝不能接触带电焊盘。
4. 将四个 10 mm 隔柱放在底盘四槽与转接板之间，螺丝从底盘上方穿入，用 Ø9 垫圈跨槽，底部用普通垫圈及螺母锁紧。两个板的中心对齐，适度拧紧。
5. 线束经中央窗口或板边固定。元件、接头和螺丝头的实际最低点决定所需离地间隙。

## 中央电池位置

旧装配的 120×50×28 mm 电池参考体也在底板下方中央，与本版 PCB 体积重合。**本版将中央空间分配给电路板，电池和原绑带需要另行布置**；预览及装配 STEP 不再放置旧电池参考体，未设计新的电池支架。不能依据本模型认为电池仍可在原位同时安装。

## 已检查与待确认

已检查转接板与隔柱为有效单实体、STL 闭合、STEP 回读、PCB 64×84 孔距、两板中心一致，以及四颗 M3 螺丝穿过原 80×60 槽孔阵。底盘、两个原摆架底座、转接板、隔柱、PCB、螺丝、螺母、垫圈在名义位置无体积穿插。结果不含未提供的 PCB 元件和接插件。

实际 PCB 板厚、孔阵在板边的偏置、元件和接插件高度、轮组内侧包络、离地间隙、新电池位置及实物强度尚需确认。PCB 朝底盘一侧若有高于 6 mm 的器件，需相应增高一体支柱。旧 520 整车的高度不作为当前新轮组的离地尺寸依据。
