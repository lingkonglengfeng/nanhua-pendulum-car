# Ø32 圆形 AS5600 模块的 V3 安装方式

本版针对用户给出的圆板图纸，不再采用 V1/V2 的方形模块占位。只需把 **08 号编码器背板换成 V3**；01–07、09、10 都沿用 V2。底座不用重打。V2 的受力圆角全部保留。

## 图纸与选定尺寸

| 项目 | 尺寸 mm | 依据 |
|---|---:|---|
| PCB 外径 | 32 | 用户图纸 Ø32 |
| PCB 厚度 | 1.6 | 用户图纸 |
| 安装槽宽 | 3 | 用户图纸 |
| 水平槽圆弧中心半径范围 | 8–11.5 | 图中 Ø16、Ø23 与 3.5 的标注解读 |
| 四个斜槽圆弧中心半径范围 | 9.5–14 | 图中 Ø19、Ø28 与 4.5 的标注解读 |
| 本次四个固定点 | X/Z 各 ±8.5 | 选在四条斜槽中部，形成 17×17 方形孔阵，对角孔距约 24.04 |
| 背板通孔直径 | 2.8 | 配 M2.5 螺丝，PCB 原槽仍为 3 |
| 背面插座宽度 | 8.3 | 用户图纸 |
| 插座凸出 PCB 背面 | 4.3 | 用户图纸 |
| 模块总厚 | 7.7 | 用户图纸 |
| 芯片凸出 PCB 正面 | 1.8 | 按 7.7−4.3−1.6 推得的名义值 |
| 绝缘隔柱长度 | 6 | 设计选定，给 4.3 高的插座留 1.7 名义余量 |
| 磁铁表面至芯片封装表面 | 初始 1.5 | 可沿原滑轨调整，装好后读取磁场诊断确认 |

孔阵 17×17 是在可调长槽内选择的固定点，不是声称 PCB 原图标了 17×17。装配方向为：芯片面朝磁铁，两个 GH1.25 插座朝背板。模块上下方向以图中两个插座分别在上、下为准。

插座在板面方向的深度未单独标清，模型按 4.5 的包络预留；芯片平面包络按 5.2×6.2 绘制以覆盖芯片与引脚。没有据此推断插座引脚顺序，也没有把尺寸图当作电路图。

## 本次需要的固定件

| 物料 | 数量 | 说明 |
|---|---:|---|
| M2.5×16 低头/盘头螺丝 | 4 | 优先尼龙或非磁性材料；模型按螺丝头加前垫圈总凸出不超过约 2.2 校核 |
| M2.5 螺母 | 4 | 装在背板后面 |
| M2.5 平垫圈，外径约 6 | 8 | PCB 芯片面 4 个，背板螺母侧 4 个；跨住长槽，勿过紧 |
| 穿孔绝缘隔柱，长 6、外径 6、内径约 2.7 | 4 | 用尼龙隔套，不是需要热熔安装的铜螺母；长度别买成 3 |
| GH1.25-4P 配套线 | 至少 1 条 | 随模块购买匹配线；两个插座的功能与引脚由卖家提供，不能直接假设相同 |

螺丝从芯片面向背面穿入，顺序为：**螺丝头 → 平垫圈 → PCB 斜槽 → 6 mm 隔柱 → 打印背板 → 平垫圈 → 螺母**。所列 16 mm 长度是螺丝头以下；实际螺丝头、垫片厚度不同，需核对磁铁侧间隙和螺母啮合。

## 安装步骤

1. 打印 V3 的 `08_encoder_carrier` 一件，检查 Ø2.8 小孔和上下两个圆角出线窗口，清除毛刺/支撑。不要整体缩放模型。
2. 用 4 个隔柱与 M2.5 螺丝，把模块的四条斜槽固定到背板 17×17 孔阵上。先轻拧，调整芯片中心与背板中心重合；长槽不能自动保证对中。
3. 接上配套线，使线缆经上下开窗或从板边引出。隔柱让插座位于 PCB 与背板之间；开窗为插座/插头与线缆提供额外避让，但实际配套插头未在图中给出，应试插确认。
4. 背板两脚放回原 07 号滑轨，仍用两颗 M3×20 固定。名义位置比 V2 向远离磁铁方向移动 3.9，但以实际芯片表面间距为准，不需要按尺死锁这个位移。
5. 先把磁铁到芯片封装表面的距离调至约 1.5，转轴手动转满一圈，确认磁铁座、PCB 固定螺丝和线缆互不碰撞。
6. 按卖家引脚图接通供电与 I²C。核对磁铁检测、磁场强弱/AGC 与连续角度读数，确认后再固定线缆和进入控制调试。

图纸未给赠送磁铁规格，09 号座继续按 Ø6×3 直径方向充磁磁铁设计。如果实物赠送磁铁尺寸不同，应换匹配磁铁或单独改座，不能硬塞。

AS5600 数据手册给出的典型磁隙为 0.5–3，实际取决于磁铁；建议利用 AGC 辅助调节。对于 6 mm 参考磁铁，手册要求轴心相对芯片中心偏移不超过 0.25。打印装配不能只靠目测，需要松开模块螺丝微调并检查读数。[芯片数据手册](https://files.seeedstudio.com/wiki/Grove-12-bit-Magnetic-Rotary-Position-Sensor-AS5600/res/Magnetic%20Rotary%20Position%20Sensor%20AS5600%20Datasheet.pdf)

## 已完成的验证

- 01–07、09、10 的 STL 与 V2 完全相同，08 才是需要更新的打印件。
- 四个 M2.5 螺丝轴线均落在对应斜槽内，PCB、隔柱、插座包络与固定打印件无体积交叠。
- 磁铁座整圈包络与芯片、PCB 和保守螺丝头包络不相交。
- 背板安装脚螺丝位于原滑轨的可调范围，上方工具接近空间通过检查。
- 全部 STL 为封闭正体积网格，装配 STEP 回读通过，零件仍适合 A1 mini。

这些是模型与图纸条件下的验证。配套插头外形、实际模块公差、磁铁磁场、实物打印和稳摆控制仍需装机检查。
